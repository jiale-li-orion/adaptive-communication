# 主张表

**每条主张只有一个当前状态。** 本表是整个仓库跨论文阶段的唯一 claim-state authority；叙事文档（含 README）只做当前投影，不承担研究历史。`B*` 命名空间保存 Layer-1 benchmark / construct-validity 主张，`C*` 命名空间保存原系统论文/通信底座主张，`A*` 命名空间保存早期 Agentic Communication deterministic / infrastructure 主张，`F*` 命名空间保存当前 **Future-Choice** representation / method / cross-domain transfer 主张。被撤回的主张移入本文件末尾的撤回表并留下 `superseded_by` 指针，其详细过程保留在作者本地的 `docs/` 归档内。

真实 LLM 效果主张只在完整坐标、正式审计和冻结输入/执行链全部通过后进入本表。A7/A8 是当前 model-effect claims；其范围严格限定在 DeepSeek Flash、三个开发任务、五个 simulator seeds 与冻结的 protocol-v6 / same-interface WOA-style comparison，不外推为跨模型泛化、主动取证算法、独立依赖求解算法或对 WirelessOpsAgent 官方实现的复现结论。

状态取自六个值，含义固定：

| 状态 | 含义 |
|---|---|
| `supported` | 有确定性、仓库可复现的证据支持，且已相对普通对照核实 |
| `scoped-negative` | 负结果，适用范围限定在所测策略族与工作点，不构成最优性定理 |
| `formative` | 形成性证据，用于定位接口问题，不用于确立机制 |
| `open` | 尚未判定 |
| `reproduced-externally` | 由本仓库之外的独立复现支持 |
| `retracted` | 已撤回，见撤回表 |

「冻结提交」不写在本表里。每个参考结果文件的最后一次修改提交由 `code/experiments/audit_claims.py` 在运行时用 `git log` 计算并打印，避免手填的提交号与 git 历史脱节。
