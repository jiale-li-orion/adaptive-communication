# C9 撤回：v1 口径下的"三方零差额、方向关闭"不成立

日期：2026-09-20。来源提交：`a665642`（C9 首次入库）。性质：结论撤回 + 契约修正。

## 撤回了什么

`a665642` 把 C9 记为 `supported`，并据此判定"中间行已建成、方向已关闭"，理由是受检格上
非预知最优、最强普通组合与全知参照都拿到满窗义务，两个差额与恒等式残差全为 0。**该结论撤回。**

## 为什么撤回（两处契约错误，均有可直接运行的反例）

见 `code/experiments/audit_seqref.py` 第 5 节与 `results/c5_seqref.json` 的 `counterexamples`
字段（独立审阅记录在本地过程材料 `local_experiments/c5_lease/review/`（**不随仓库发布**）；其中的反例已由随仓库发布的 `code/experiments/audit_seqref.py` 与 `results/c5_seqref.json` 的 `counterexamples`／`endpoint_invariance` 字段复现，因此克隆可自行核对）：

1. **真值终点替策略自动降档**。v1 的 `evaluate_rule` 只把规则执行到黄级窗口终点 `down_h`，
   随后接上"此后始终稀疏"的安全性；DP 采用同一边界。这等于免费给了节点"真实授权结束时本地
   终止"的能力——正是 C5 要研究的缺口。
   * 见证一：一个永远返回"继续密集"的规则被评为 `safe=True`、满窗 48/48、无主动终止。
   * 见证二：把 `TTL8 + 8 mWh 门`真正执行到它自己的结束时刻（h10，而不是在未知的 h6 自动降档），
     在声明的低采能未来里最低电量为 **0.3295 mWh**，低于模型的 0.47 mWh 安全线。v1 却把它列为
     安全满分并列成员。
   * 见证三：同一动作表、同一小时、同一电量格，只把不可见的 `down_h` 由 6 改成 10，
     `policy_dense` 输出由 False 变成 True。
   DP 与穷举共享该边界，所以二者一致**不能**排除这项错误（它们验证的是递推，不是信息条件）。
2. **等权三点没有匹配声明的标准差**。`{μ−s, μ, μ+s}` 等权时 `std = s·√(2/3)`，因此 `s=.047`
   对应真实标准差 **0.03838**，不是 0.047。要保持等权并匹配 0.047，偏移须为 **0.05756**，
   它超过 v1 报告的 `s_full=.0510` 与 `s_sparse=.052599`（后两者本身也是偏移量而非标准差）。
   于是"实测离散度下仍有 8.5% 余量"不成立。按正确偏移取声明集合允许的持续低采能未来，
   **全程稀疏的最低电量即为负（−8.69e-6 Wh）**：由逐拍单调性，该格在该风险口径下无可行策略，
   不能继续记成三方满分。

第三处（规范逻辑）：v1 §1 的关闭规则把"可实现差额"与"信息差额"混为一谈。二者可以同时为正
（普通 60、非预知 80、全知 100），可实现的那部分不因仍低于全知而被取消。已改。

## 处置

| 项 | 处置 |
|---|---|
| C9 状态 | `supported` → **`open`**；"方向已关闭"的表述从全部正式入口撤下 |
| v1 结果 | 保留为 `results/c5_seqref_v1_semantics.json`（活文件与冻结快照各一份），**不覆盖** |
| v1 预注册 | 保留原文，标为被 v2 取代 |
| 契约 | 新写 `spec/prereg-nonprescient-sequence-v2.md`：隐藏终点不得改变执行；σ 与偏移分开声明 |
| 核例 | 保留（DP = 穷举 = 20.0、最强安全固定租约为 12.0）；其意义限定为**递推验证** |
| 校准记录 | 保留。射频负载预测偏高的机制解释不变，仍是"候选失败限于所测实现"的依据 |
| C5 | 不受影响，维持 `scoped-negative`；原网络三种子的比较不被本撤回撤销 |

## 没有被这次撤回触动的东西

* C1–C8 与 C5 的现有读数。
* 目录、登记、检查、冻结参考这一套体系。
* 本模型对真实部署可行性的任何判断：撤回只限定"这个不确定集合 + 这个风险口径"，
  不主张真实站点物理不可行。
