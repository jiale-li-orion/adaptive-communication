# Stage-2 发现与预注册修订（能量硬预算 × 强基线到顶 × 干净归因）

> 本文件是对第一版冻结预注册（README.md）的**带时间戳修订附录**，不回改第一版。
> 动机、每一步基线加强、以及被自己拦下的 strawman 全部如实记录，避免"调到赢"的解读。
> 对应结果：results/probe_results.json（第一版）、budget_sweep.json、info_vs_policy.json、final_arms.json。

## 1. 为什么要做第二版（第一版诊断）

第一版（无能量硬约束）主结果：oracle≈rule_mpc（ΔE −0.8～+0.24pp，区间普遍跨0），只有 fixed 落后 6–15pp。
资源审计定位机制：rule_mpc 比 oracle 多耗 25–50% 能量（每任务在坏路径空发 500–640 次），
但因为第一版刻意去掉了能量硬约束，**这些浪费不转化为业务损失**；rule 在收费卫星上信念很准（配额浪费仅 6–12 条）。
结论：**"隐状态+多路径"单独不足，信息差必须撞上"误判代价不可逆"才兑现。** 最真实的不可逆代价是能量
（与主 repo"能量时序决定生死"一致），故第二版加等预算能量硬约束。

## 2. 强基线是怎么一步步"做到顶"的（含一次被自己拦下的退步）

为避免重蹈主 repo"弱基线 strawman 胜利"的覆辙，非全知基线被刻意加强到传统方法天花板：

1. **rule_mpc（单拍 fractional-knapsack）**：HMM 最优滤波（用真实 GE 转移参数）+ 期望成功/能量效率贪心
   + 目标轨迹能量配给。
2. *两档分配（已废弃的弯路）*：曾按"高信念发满/不确定档限速"分两档，结果不确定档被过度限速、
   iid 下交付反降到 52%——属于人为削弱，废弃，回退到统一 knapsack。
3. **belief_mpc（最终传统天花板）**：信念状态随机模型预测控制。用真实 GE 模型对未来 H=6 拍做 S=12 条
   信道情景采样，在 6 个能量激进系数 α 中选期望目标最优；event 用两龄桶精确维护 2h 截止期；
   **不预知未来 event（用平均到达率）、不看当前真实状态（只用 HMM 后验）**。

### 干净归因（关键方法）：把"信息"与"算法/配给"分离

- `cheat_mpc`：与 belief_mpc **同一个求解器**，唯一差别是当前状态信念被替换为真实点分布。
- 若 oracle−cheat_mpc≈0，说明求解器/能量配给本身已追平全知上界，则 oracle−belief_mpc 才是**纯当前状态信息价值**。
- 实测 **oracle−cheat_mpc 在全部 cell |Δ|<0.8pp、95%区间全部跨0、W/L 对半** → 求解器自检通过，归因干净。
  （中途曾出现 oracle−cheat=3–9pp，定位为能量目标轨迹对"知道当前好"的臂也次优限速；改同一 MPC 求解器后消除。）

## 3. 最终结果：纯当前状态信息价值 = oracle − belief_mpc（事件交付率，pp，配对 20 种子，[95% CI] W/L）

| budget | iid | chirpbox（真实拟合，平均坏突发6.49h） | heavy（更长坏突发） |
|---|---|---|---|
| loose（无能量约束） | −0.80 跨0 | −0.45 跨0 | −0.73 跨0 |
| 2100 | 2.60 [1.14,4.06] 16/4 | 1.42 [−0.23,3.08] 跨0 | −0.45 跨0 |
| 1950 | **5.73 [3.39,8.07] 17/2** | **4.27 [2.40,6.14] 16/3** | 1.74 [0.12,3.35] 14/5 |
| 1800 | **11.15 [8.56,13.73] 20/0** | **8.19 [4.54,11.85] 19/1** | **3.78 [1.34,6.23] 14/5** |

参照：同 cell 普通 rule_mpc 与 oracle 的差（or−rule）在 chirpbox/1800 为 14.65pp、iid/1800 为 18.26pp——
即**信念 MPC 把表面差距吃掉了约一半到三分之二，剩下的才是任何"基于历史的模型化方法"都吃不掉的残差。**

后验判别力诊断（diagnose_belief.py）解释了跨 burst 的规律：
- **iid**：链路逐拍独立，HMM 后验恒等于先验 0.688（好/坏态后验完全重合、坏态误报率 100%），
  当前状态在原理上无法由历史推断 → 信息价值最大；
- **chirpbox**：持续期后验较准（好态中位 0.929），但坏态误报 28.5%、稀疏使用的卫星坏态误报 83.6%，
  模糊集中在状态翻转边界与备用路径 → 信息价值中等；
- **heavy**：坏突发最长、证据积累最充分（坏态中位后验 0.05、误报 14.3%），历史最能推断当前 → 信息价值最小。

## 4. 结论：GO，但 go 的是一个被精确定界的狭窄空间

**结构三元组（缺一则复现负结果）**：当前状态隐状态 × 多路径（有替代手段）× 不可逆稀缺（硬能量预算）。
- 无能量约束：所有非 fixed 臂≈oracle（复现主 repo 旧负结果）；K=1 单路径：P1 差 −0.83pp（信息无替代路径可用）。
- 三元组齐备时，信息价值随**能量收紧**单调增大（跨0→区间不跨0），随**信道可预测性下降**而增大
  （heavy<chirpbox<iid）——这是一张"控制信息何时值钱"的相图，而非"agent 普遍更优"。

**对照事前 gate**：真实 chirpbox 信道、紧能量档（1950/1800）下，对**最强传统基线 belief_mpc** 仍有
4.3–8.2pp、95%区间不跨0、配对 16/3～19/1 的稳定残差 → 超过"<2pp 且跨0"的硬 no-go 判据，**判定 GO**。

## 5. 对第二阶段（接 LLM agent）最重要的诚实边界

oracle/cheat_mpc 用的"当前真实状态"，**LLM agent 同样拿不到**；且 HMM 已用真实 GE 参数做到最优在线滤波，
"LLM 推断隐信道状态比正确生成模型更准"不是一个可辩护的假设。因此 agent 不可能在"数值能量优化"上赢 belief_mpc
（那正是主 repo 三次证伪的形态）。残差能被 agent 吃到的**唯一可信路径是 model mismatch / 开放语境**：

1. **模型错配与分布漂移**：MPC 依赖"真实转移参数已知且平稳"。现实中 GE 参数需在线估计、会漂移、会遇到
   分布外信道（地形/天气/设备老化）。检验：给 MPC 错误/漂移的转移参数，看其优势是否塌缩；agent 用多实体
   经验与语义上下文做鲁棒适应。
2. **非结构化侧信息**：MPC 到达模型只用固定均值；agent 可融合灾情通报、天气预报、任务优先级语义来预判
   "未来何时更需要留能量"，这是参数化 MPC 装不进去的输入。
3. **观测/探测的开放式价值判断**：同通道下"花不可逆能量探测 vs 直接赌 vs 静默等待"、多实体间探测谁，
   MPC 只能在给定模型内算 VOI；异常观测该不该信、何时换模型，是 agent 的空间。

**第二阶段实验应比较：在模型错配/漂移/带侧信息条件下，belief_mpc（依赖正确模型）vs agent（鲁棒、融合语义）**，
并配三个消融：去隐状态、去多路径、去不可逆代价（逐一拆掉三元组，优势应消失，复用主 repo 负结果作对照）。
若在"模型正确且平稳"的理想条件下就让 agent 打 MPC，那是基线没做好，不算数。
