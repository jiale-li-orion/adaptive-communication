**不修改、不重跑、不污染** v1.1 实例；目的只有一个：用最便宜的方式回答一个战略问题——

> **当回传从"单条"变成"多条异构、状态隐藏、观测要花真实成本"时，只看合法观测的强规则/MPC
> 与全知 oracle 之间，是否存在稳定、且随路径数和链路突发度增大的差距？**

- **有差距（go）**：存在经典规则吃不到的可利用空间，才值得把 LLM agent 接进来填，"agent+应急通信"方向复活。
- **规则贴着 oracle（no-go）**：连全知带来的好处都很小，或强 MPC 已能逼近，则多路径也救不了方法主张，正式止损。

## 0. 为什么需要它（与主 repo 结论的关系）

主 repo 已证明：单网关、单回传、中心只能动 `sampling_interval/report_period` 两个字段、本地自治强的
实例里，agent/复杂策略相对强规则无业务收益（doc31–54）。本探针检验的假设是：**那不是 agent 的死刑，
而是动作面/观测结构把 agent 的比较优势移除了**。`system-model.md:19` 早已写下关键结构
（"实体静默 vs 我的查询在回程丢了，观测上不可区分"），但 D3 把多实体退出第一轮后该结构从未被实例化。
本探针把它最小地加回来。

**主 repo 的负结果在这里充当消融边界（事前预测，见 §5）**：单路径时 oracle 与规则应当重合——
这正是已测到的"agent=规则"，它从失败变成新框架的边界证据。

## 1. 抽象范围（刻意收窄，一次只隔离一个机制）

- 决策层：**网关 → 中心的多路径回传选择**。节点 → 网关那跳沿用主 repo 既有结论，不重做。
- 离散时间，1 拍 = 1 h（对齐 ChirpBox 小时级拟合），任务 336 h（14 天）。
- 网关每小时产生待回传样本（routine + event），样本有截止期与价值；在多条异构上行路径间分配发送。
- **本版不引入能量硬约束**（能量维度主 repo 已研究透，避免混淆）：能量/货币只记成本账，不卡死；
  稀缺资源是**路径真实状态不可见 + 卫星日配额 + UAV 短接触窗口**。能量硬约束列为下一版扩展。

## 2. 环境：三条异构上行路径

每条路径真实好/坏状态由独立两态 Markov 链生成，**状态序列只由 (seed, 路径, 拍) 决定，与策略无关**
（跨臂配对的前提）。控制器**看不到**真实状态，只能看到自己在该路径上历次尝试的成败。

| 路径 | 边际可用 | 突发参数（好→坏 / 坏→好，每小时） | 带宽 cap | 成本 | 特殊约束 |
|---|---|---|---|---|---|
| `cellular` 蜂窝/NB-IoT | 0.688 | **0.0712 / 0.1567**（ChirpBox 实测拟合，坏突发均长 6.38 h，E 级来源） | 6 条/h | 能量 1，货币 0 | 无 |
| `satellite` 短数据卫星 | 0.962 | 0.020 / 0.500（高可靠、坏态短，A 级研究假设） | 2 条/h | 能量 3，货币 1 | **日配额 24 条/天，失败也扣配额**（短报文空口/计费事实，A） |
| `uav` 过顶中继 | 时刻表 | 计划窗口每天 02–03h、14–15h；计划窗口实际取消概率 0.1（A） | 20 条/h | 能量 0.5，货币 0 | **窗口外不可用；时刻表公开、是否取消隐藏，试了才知道** |

好态下单次发送仍有 0.05 随机丢包，坏态单次发送成功概率 0.02（A 级观测模型参数）——
于是"一次失败"既可能是坏态、也可能是好态随机丢包，**不可区分**，这正是隐状态问题的来源。
`uav` 用 DTN 侦察报告的 contact-plan 形态：确定性时刻表 + 概率性取消，而非 Markov。

样本到达（外生，所有臂相同）：routine 4 条/h，截止期 12 h，价值 1；event 为外生突发
（14 天 6 次、每次 2 h、每小时 12 条，截止期 2 h，价值 5；形状参考 Wang 七事件，A 级简化）。
队列上限 200，溢出先丢最旧 routine、event 优先保留（固定、公开规则）。

## 3. 三个臂（同信息/同动作/同约束，只差"状态信息"与"算法"）

1. **`oracle`（上界，非未来预知）**：每拍看到三条路径**当前**真实好/坏；仍受带宽/配额/窗口约束，
   **不预知未来转移**。在当前真实可用路径内按"单位成本→带宽"排序、EDF（截止期早者优先）分配。
   从不在坏路径浪费、无需探测。它隔离的是"状态信息完全"的价值。
2. **`rule_mpc`（强规则，刻意做强，不是稻草人）**：只看自己的尝试历史；用**与生成过程相同的真实
   转移参数**做 HMM 后验滤波得到各路径 belief；按期望可用容量/成本做滚动贪心 + EDF；带**价值信息探测
   （VOI）**：当某路径 belief 落在不确定带 [0.3,0.7]、积压超阈值且探测可负担时，先花 1 条试探再加注。
   给它真实转移参数是**偏惠规则**的设定——这样它若仍落后，结论才硬。
3. **`fixed`（工程现状下界）**：固定优先级 cellular→（连续失败 3 h 才切）satellite，uav 仅计划窗口内、
   且 cellular 失败时用；不维护概率、不探测、不滚动。

所有臂：相同 seed 下路径状态/到达/事件/时刻表/配额/队列**逐拍相同**；动作集合与约束相同；
独立 scorer 根据真实结果判定每条样本是否按期送达，控制器不自记分。

## 4. 指标（分列，不造统一分；配对）

- 主指标：**event 按期交付率、routine 按期交付率**（外生固定分母，各臂一致）
- 分列：逾期丢失（event/routine）、发送尝试、成功、**在坏路径上浪费的尝试**、
  卫星配额消耗与浪费、队列溢出、能量/货币成本
- 统计：N=20 配对种子，逐种子 `oracle - rule_mpc`、`rule_mpc - fixed` 的均值差与 95% t 区间
  （沿用 `code/analysis/paired_ci.py` 的配对法），并报 win/tie/loss 与逐种子零检查（zero is a claim）

## 5. 事前可证伪预测（结果出来前冻结）

扫描轴：路径数 K ∈ {1,2,3}（K=1 只留 cellular；K=2 加 satellite；K=3 全有）×
突发度 b ∈ {iid, chirpbox, heavy}（iid=同边际独立；chirpbox=6.38h 坏突发；heavy≈20h 坏突发，LoRa-on-Ice 级）。

- **P1（sanity/消融边界）**：K=1 时 oracle 与 rule_mpc 差距≈0（无选择空间、单链信息不对称无法利用）。
  若 K=1 就有明显差距，说明仪器有 bug，结果不可信。
- **P2（主假设）**：K≥2 时 oracle−rule_mpc > 0，且**随 K 增大、随 b 加重而单调增大**
  （路径越多/突发越长，隐状态越难，MPC 越容易在长突发里误判：把坏当随机丢包而持续浪费配额，
  或把已恢复当坏而错过 UAV 短窗口）。
- **P3**：fixed 在 heavy 突发下明显劣于 rule_mpc（证明朴素故障切换不够，但这不是主结论）。
- **证伪条件（no-go）**：若 K=3、heavy 下 oracle−rule_mpc 的 event 交付率差仍 <2 个百分点且区间跨 0，
  说明强 MPC+真实转移参数已足够，多路径隐状态不构成规则的结构性弱项 → **不接 LLM，此方向止损**。

## 6. go/no-go gate（下一步只在 go 时发生）

- go：P1 成立（仪器可信）且 P2 成立（差距稳定、随结构放大）→ 第二阶段才接 agent：
  相同合法观测下，比较 rule_mpc 与"带 belief/backpressure/authority-gate 的 LLM agent"，
  检验 agent 能否吃到 oracle−rule 之间这块空间；同时做"去隐状态/去多路径/去非平稳"的消融，
  优势应随之消失（复用主 repo 负结果）。
- no-go：P2 不成立 → 记录关闭，不再以"加路径让 agent 赢"重试。

## 7. 复现

```bash
cd "agentic communication"
python3 multipath_probe/run_probe.py                 # 跑 K×b 扫描，写 results/probe_results.json
python3 multipath_probe/test_probe.py                # 不变量自检
```

参数来源分级：E=外部来源直接支持（ChirpBox 拟合 `results/loss_model.json`；Wang 突发形状；
DTN contact-plan 形态），A=研究参考假设（卫星/取消率/观测模型/到达率/配额/带宽，均在 §2 标注，
不冒充现场事实）。本探针不使用任何 LLM、不调用网络。
