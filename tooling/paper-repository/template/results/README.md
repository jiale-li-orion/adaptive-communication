# 结果文件登记册

本目录的每个结果文件都由仓库内脚本产生，不手工编辑。每条给出：产出脚本、可复现命令、种子或轨迹、
以及它可以被引用来说明什么。**登记是引用的前提**：存在于磁盘而不在本登记册里的结果文件由检查报红。

**本地材料说明。** 本文件引用的仓库外路径属于作者本地的过程文档，不随本仓库发布。

## 登记格式

| 文件 | 命令 | 种子 | 说明什么 |
|---|---|---|---|
| `example_metric.json` | `python3 code/experiments/example_metric.py` | 5 | 模板示例：一条确定性读数，用于验证接线。换成真实结果时删除本行。 |

## 规则

新增结果文件时同步登记，说明口径与分母；口径或分母变化时同时更新本行。冻结判定基准放
`results/reference/`，两者出现差异是信号而不是噪声。
