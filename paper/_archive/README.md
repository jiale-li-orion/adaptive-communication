# Paper archive index

This directory contains immutable paper/planning snapshots that have been superseded by a newer manuscript or research plan. Archive entries are provenance, not current claim authority.

Rules:

1. Each archived object records `superseded_by`, `reason`, and `source_commit` in its own README/header.
2. Archived manuscript text is not edited to follow later claim corrections. Current claim state always comes from `results/CLAIMS.md`.
3. Corrected compatibility manuscripts may remain outside this directory when old claims still need to build against current frozen result semantics; they are not substitutes for the immutable snapshot.
