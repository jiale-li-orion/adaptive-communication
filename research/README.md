## 更新规则

方法设想与下一步改在 ROADMAP；文献新增改在 RELATED_WORK 和 sources；实验结果仍登记 results。完成一个里程碑后更新阶段，不再为每次尝试生成一份新的「最终路线」。关闭具体候选时保留失败机制、可复用实现与适用边界，不能据此关闭整个场景。
