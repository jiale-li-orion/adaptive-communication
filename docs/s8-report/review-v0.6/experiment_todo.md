# v0.6 审查后的最小执行计划

状态：计划待执行；本轮未调用 API、未启动新方法。目的限于修复和判别现有论文，不扩研究场景。主审查 [doc51](../../s7-method/v1.2/51-independent-review-paper-v06-2026-09-19.md)。

## 第一批：无需新增 LLM 调用

1. **E-R1：冻结运行账与准确计数。** 用现有 11 条 trace 输出按臂的有效 JSON、parse fallback、重试、最终响应/错误；已完成的本轮审计见 `evidence.json`，下一实现应把这些字段纳入正式结果与论文。不能用 `llm_calls==decisions` 证明无回退；不能剔除发生回退的 tick 后把整条轨迹继续当作纯 LLM。
2. **E-R2：重标声明。** 审全部 43 条 regex 阳性、A1 全量 note，并抽检阴性；标记要求/计划/确认/链路判断/条件性不可行/unknown。核验主体、时间与证据。为正常组启用相同评分。产物为带 trace 行号的标注表、混淆表、修正读数。暂不要求额外模型。
3. **E-R4：局部可见性审计。** 分离 node/gateway/center 的日志；对每条事实要求拥有者位置与 received_at。当前 427 条未来 heard 见证应全部不再进入 ka=72000 的局部诊断；不公开不可见采样历史。报告 unknown 比例以及可判定部分精度。追加同历史、不同隐状态的非预知见证，不能“修到仍然 100%”作为目标。
4. **E-R5：expiry 语义对照。** 把现有 purge 明确写成 `expires_at=(taken//P+2)*P`，与同期限的普通源端 expiration 比较决策集合。预期可能完全等价；等价时停止算法新颖性主张，保留 failure analysis。若声称新跨段协议，指出现有实现中独立于 TTL 的消息、状态与状态迁移，不能用同算法改名造基线。
5. **W-R6/R7/R8：文稿收窄。** 删除任何控制器无空间、纯本地上界、普遍安全保证、已经修复 A1 四死、全项目未见种子和 API 零回退等未支持表述。这是写作任务，不需新仿真。

## 第二批：只有剩余独立机制成立才启动小对照

| 实验 | 回答什么 | 公平反方 | 必要产物/闸门 |
|---|---|---|---|
| E-R3a | A1 增益是否仅是更具体的常识/策略说明 | 同原始常量、同 dayfeed/确认规则说明、同输出 schema、同历史的 A0s | 先在已有决策快照上比较；不能把新建议文本同时当“唯一证书变量” |
| E-R3b | 合法结构证据是否有增量 | 以上普通规则说明 + 普通 shadow/reconciliation；各臂共享 L0 安全底座 | 只测已发现的自然失败窗口及正常对照；报告误报不可行/漏报/合法可执行动作误拒、实际成本，不能只测是否停止 dense |

第二批前先固定 API 响应模式/解析契约和逐请求账。观察到提示词格式改善可以报告，但要与义务链推理增量分列。若普通规则文本或同期限 expiry 覆盖全部增量，就把相应部分收为标准机制的实例化，不再扩大种子来挽救方法名。

## 完成判据

- 保留一个明确的、原始证据可复现的 failure mode。
- 每个在线结论只依赖该位置在该时刻实际收到的事实；unknown 允许存在。
- 新增量相对于同能力的普通实现测出，或诚实记录“未测到”。

这组判据通过后再决定主文贡献重心；不把修完格式、通过 18/18 或增加图数视作论文闭环。
