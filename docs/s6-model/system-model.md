# 系统模型（论文 Section II 初稿）

按 JSAC/TCOM/TWC/TMC 的惯例组织。小节骨架取自同类论文的实际结构，其中 **II-C-3 地形** 与 **II-F 失效与中断模型** 两节是本文的差异化门面——对 9 篇同域论文的通读显示，前者 0 篇涉及，后者 0 篇设立。

证据层标注：**M** 实测、**S** 标准模型、**F** 拟合、**A** 假定。A 层须做敏感性扫描，不得当作实测值报告。

## II-A 网络架构

底层资源是通感算一体化的多实体集合。监测节点在坡面，经 LoRa / NB-IoT 接入；弱覆盖处经 CPE 或 UAV 中继汇聚；回程走微波 / HAPS / 卫星。集合中的每个实体带角色与基础设施类型，并投影成 agent 可调用的 capability。实体类型与灾损断点的对应关系见 README 第二节与其原始文献。**S**

本文不研究该用哪一类实体，集合的选取已有答案。本文研究的是该集合随时间变动时任务如何继续。

## II-B 部署与拓扑

研究区域为西藏波密与易贡一带，已记录的最大规模滑坡发生地之一。地形取真实 SRTM1（1 角秒，约 30 m），瓦片 N30E094 及相邻三片，原始海拔跨度 2025 至 6690 m。**M**

网关单点架设在 (30.330°N, 94.780°E)，海拔 2317 m，处于谷地，四周山脊高出 3300 m 以上。这一选择是场景的一部分：山区监测的现实形态就是谷地汇聚点加坡面节点。**M**

节点布点在网关周围 121×121 格点上，点距约 204 m，覆盖 0.22°×0.22°。格点间距由高程数据与计算预算共同决定，不是物理量。**A**

## II-C 信道模型

信道分两段，空间维与时间维来源不同，不可混为一段。

### II-C-1 地面链路：地形损耗

用 Longley-Rice ITM v1.2.2 点对点模式，沿大圆路径按 DEM 原生分辨率采样，4/3 等效地球半径。参数：868 MHz、发射 14 dBm、两端天线增益 2 dBi、馈线 1 dB、带宽 125 kHz、天线高 2 m、地面 ε=15 与 σ=0.005 S/m、大陆温带气候、mdvarx=11、可靠度 90%。**S**

公里与兆赫口径下自由空间损耗为 `20log10(d_km) + 20log10(f_MHz) + 32.44`，总损耗为 `FSPL + avar`，其中 `avar` 返回所请求分位的总衰减量。平坦地形回归必须复现两径地面反射模型。**S**

### II-C-2 时间维：链路好坏的时间相关结构

用 Gilbert-Elliott 两态模型，参数由 ChirpBox 真实 LoRa 轨迹拟合：20,913 快照、21 节点、420 条有向链路、878 万次状态转移，得 `p(g→b)=0.0243`、`p(b→g)=0.3026`，平稳丢失率 7.44%。平均下行突发 3.30 h，上行突发 41.09 h。同丢失率下 i.i.d. 模型只预测 1.08 h，相差 3.06 倍。**F**

ChirpBox 采自上海城区。借用的是时间相关结构，不是绝对水平。**效力威胁**

### II-C-3 地形考虑

本节是本文与同域文献的主要分野。对 9 篇近期 JSAC/TCOM/TWC/TMC/TVT 同域论文的通读显示：**没有一篇使用 DEM、地形数据库或实测信道 trace 来论证仿真真实性**。地形最多作为几何抽象出现（一个环形部署廊道），多数完全缺席；3GPP TR 38.901 参数表的使用为 0 篇。

真实地形给出的结果与距离主导的直觉相反。**M**

| 节点 | 距离 | 遮挡高度 | 自由空间损耗 | L50 总损耗 |
|---|---|---|---|---|
| valley A | 8.37 km | 1169 m | 109.7 dB | 217.0 dB |
| far E | 12.61 km | 1102 m | 113.2 dB | 201.2 dB |

距离近 4.2 km 的点位反而差 15.8 dB。遮挡造成的超额损耗在 71 至 107 dB 量级，而 SF 从 7 提到 12 只增加 14 dB 灵敏度，链路自适应因此无法救回被地形挡住的节点。

单网关在 121×121 网格上的可达点仅 1689 个，占 11.5%；连不通的 12952 个，占 88.5%。可达点损耗中位数 113.4 dB，不可达点中位数 206.6 dB。**M**

独立做的几何视线判定给出同一量级的结果：原生分辨率下仅 6.6% 的格点与网关有清晰视线。几何判定采用 DEM 剖面加第一菲涅尔区净空判据，该判据在山区 LoRaWAN 场景中与实测连通性的一致性有已发表证据（Torres-Sanz 等, *Internet of Things* 38:102012, 2026）。**S/M**

## II-D 能量模型

高海拔站点的失效由供电而非无线决定。

储能取 LiFePO4：−20 °C 下可用容量约为标称值的 50%，低于 +5 °C 无法充电。**S/M** 发电取光伏，气温基线由海拔推导：3925 m 处 1 月均温约 −19.5 °C、7 月约 −7.5 °C，日间温度全年低于充电下限。

三条反直觉结论。面板从 30 W 增到 200 W，停电率恒为 93.7%，发电被温度闸门掐死而非被能量禀赋限制。积雪掩埋的概率从 0 扫到 0.20 每天，停电率不动，因为它在充电闸门打开之前不构成约束。杠杆只有电池化学、加热电池箱，或降低站点海拔。**M（模型输出）**

气候基线整体平移 ±6 °C，停电天数在 342 天附近不变，只有夏季均温升到 0 °C 以上才改善至 217 至 260 天。基线可能偏冷约 10 °C。**效力威胁**

## II-E 业务与队列

上行为周期性遥测，标称间隔 10 min 至 1 h，单包有效载荷 20 B 量级，监测对象含降雨、孔压、水位、地表位移与裂缝开度。**A**（由低功耗监测系统常见配置取定，须扫描）

下行为配置与命令，量小但必须送达：采样率调整、门限下发、休眠调度、告警确认、网关切换、中继启用。**A**

国内地灾监测项目的验收条款为广东 ≥70%、昆明 ≥95%、河南 ≥95%，但这是合同值而非实测值。公开文献中不存在中国地灾监测网络的实际到报率、在线率、掉线次数与断链时长。**效力威胁**

## II-F 失效与中断模型

本节是本文的第二处分野：9 篇同域论文无一设立失效与中断模型小节，中断在多数工作中是参数扫描的一个维度而非被建模的过程。

单个实体在时间轴上经历上线、可用、退化、掉线、恢复。对节点而言，掉线有两个独立来源，且**观测端不可区分、处置方式完全不同**：

**持续遮挡。** 由地形与传播决定，任何自适应与重传都无法挽回。占比 88.5% 的格点属此类。处置只能改架构：换位置、加中继、走中继回传。单网关加一个最优中继后覆盖升至 33.2%，中继有效但远不足以闭合。

**季节性静默。** 由能量与温度决定，冬季长静默、夏季恢复。处置是等待或加热。

现有工作普遍把两者当作同一件事，其后果是：把永久失效算作可恢复故障会高估恢复策略的价值，把季节性静默算作随机丢包会低估所需的缓冲深度。

变动的时间尺度由三处决定，彼此相差三个数量级：空间维给出 11.5% 随时可通与 88.5% 永久不可通；时间维给出 3.30 h 量级的平均中断突发；能量维给出以月计的冬季静默。任何单一尺度的评测都会漏掉另两个。

## II-G 决策问题

agent runtime 位于通信实体之上，在实体上线、掉线、退化、恢复的过程中维持任务执行。动作空间为：对某实体下发某个 capability 调用、等待、重试、改走另一实体、放弃并上报。

目标是在给定能量与频谱预算下最大化任务存续，其中"存续"必须落到可观测量，见 II-H。

## II-H 指标

| 指标 | 定义 | 说明 |
|---|---|---|
| 到报率 | 周期内应到达的采样包中最终到达的比例 | 按传感器与按时间分别统计，单一全局值会掩盖局部失效 |
| 到达时延分布 | 每包从生成到到达的时间，报分位数 | 均值被少数快包主导，监测关心尾部 |
| 能量预算余量 | 剩余能量相对越冬所需的比例 | 决定下一冬季是否存活 |
| 重复执行次数 | 同一逻辑命令被实际应用超过一次的次数 | 与任务正确性正交的执行正确性 |
| 零执行周期 | 应下发但最终未落地的命令数 | 与上一行方向相反，必须同时报 |

最后两行构成一对。只报其一会奖励错误行为：放弃执行可以压低重复率，重发可以压低零执行数。实测证据见 `docs/s5-benchmark/s6-11-execution-layer-results.md`，其中 `verified_wrapper` 把重复减半的代价是 562 个周期完全未执行。

**命名说明。** 同域文献中不存在任务级可靠性的公认指标名。可靠性普遍写作链路级的 coverage/outage probability，或服务级的 availability/feasibility rate。本文的到报率与零执行周期属任务级指标，需在首次出现处给出定义式并论证其必要性。

## 对照方案

按同类文献的句式组织，每条声明来源与实现方式。通读显示，9 篇中运行第三方公开实现的为 0 篇，6 篇以重实现或自建方式构造对照，本文沿用此惯例并公开代码。

"We consider the following schemes":

1. **单跳直连（退化消融）**：节点直接与网关通信，无中继、无 store-and-forward。给出无架构增益的下界。
2. **固定门限策略**：按静态阈值决定是否重传或切换，不感知链路时间相关性。工程惯例。
3. **ADR / 链路自适应**：依 RSSI 调 SF 与发射功率。出处 Reynders, Meert, Pollin, ICC 2017, `10.1109/icc.2017.7996380`。隐含假设是链路存在，只需调参；II-C-3 的结果说明该假设在 88.5% 的格点上不成立。
4. **DTN store-and-forward**：Fall, SIGCOMM 2003, `10.1145/863956.863960`。接触机会到来即转发；对应到本文场景需改为固定节点加 UAV 过顶计划，直接套用会高估投递率。
5. **集中式 oracle**：已知全部链路未来状态的上界，用于量化在线决策的差距。
6. **无地形版本（本文消融）**：把 II-C-1 换成对数距离路损，其余不变，用于量化地形与失效建模带来的差异。

前五条为对照，第六条为自有消融。

## 待补

- 采样间隔与载荷是 A 层，须从目标文献取实测值。
- 卫星与 HAPS 回传未纳入，当前只有地面网关一种回传。
- 中继的能量可行性未验证，3925 m 的中继能否越冬未答。
- 气候基线需用气象站数据核对。
- 失联时长的显式分布（对数正态或 Weibull）尚未拟合，当前只用了均值突发时长。
