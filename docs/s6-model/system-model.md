# 系统模型（论文 Section II 初稿）

按 JSAC/TCOM/TWC/TMC 的惯例组织。小节骨架取自同类论文的实际结构，其中 **II-C-3 地形** 与 **II-F 失效与中断模型** 两节是本文的差异化门面——对 9 篇同域论文的通读显示，前者 0 篇涉及，后者 0 篇设立。

**组织原则。** agent runtime 是本文的研究对象，因此它在 II-A 就作为架构的一等组件引入，而不是在末尾补一个决策者。信道、能量、业务三节（II-C 至 II-E）描述 agent 必须在其上工作的物理条件，II-F 给出物理变动过程**以及 agent 对该过程的观测投影**，II-G 给出 agent 本身的模型，II-H 给出目标的可观测形式。物理条件写得详细，是因为它们决定 agent 面对的是哪一种困难，不是因为它们是贡献。

证据层标注：**M** 实测、**S** 标准模型、**F** 拟合、**A** 假定。A 层须做敏感性扫描，不得当作实测值报告。

## II-A 网络架构：agent runtime 的位置

系统分三层，agent runtime 是其中最上面一层，也是本文的研究对象。

**通信实体层。** 通感算一体化的多实体集合。监测节点在坡面，经 LoRa / NB-IoT 接入；弱覆盖处经 CPE 或 UAV 中继汇聚；回程走微波 / HAPS / 卫星。每个实体带角色与基础设施类型，并投影成一个带类型的 capability。实体类型与灾损断点的对应关系见 README 第二节与其原始文献。**S**

**任务层。** 灾前滑坡与泥石流监测的持续态势维持，要求按周期取得各监测对象的读数并在异常时下发处置。任务层与实体层之间没有直接绑定：一个"取得某坡面本轮读数"的任务，可以由不同实体在不同时刻以不同路径完成。

**agent runtime 层。** 协调者。它持有任务集，唯一能做的事是对实体调用 capability，因此它的全部世界知识都来自这些调用及其返回。

**本文的关键结构性假设：agent 的观测通道与它的控制通道是同一条。** agent 没有带外信道，没有独立的健康监测接口，没有预示实体将要掉线的先知信息。它判断某实体是否可用，只能通过向该实体发一次调用并观察结果；而这次调用本身会穿过它试图评估的那条链路。于是"实体已静默"与"我的查询在回程丢了"在观测上不可区分。这一条贯穿全文，也是 II-F 与 II-G 的依据。

本文不研究该用哪一类实体，集合的选取已有答案。本文研究的是该集合随时间变动时 agent 维持任务执行的能力。

研究区域为西藏波密与易贡一带，已记录的最大规模滑坡发生地之一。地形取真实 SRTM1（1 角秒，约 30 m），瓦片 N30E094 及相邻三片，原始海拔跨度 2025 至 6690 m。**M**

节点布点在网关周围 121×121 格点上，点距约 204 m，覆盖 0.22°×0.22°。格点间距由高程数据与计算预算共同决定，不是物理量。**A**

## II-C 信道模型

信道分两段，空间维与时间维来源不同，不可混为一段。

### II-C-1 地面链路：地形损耗

用 Longley-Rice ITM v1.2.2 点对点模式，沿大圆路径按 DEM 原生分辨率采样，4/3 等效地球半径。参数：868 MHz、发射 14 dBm、两端天线增益 2 dBi、馈线 1 dB、带宽 125 kHz、天线高 2 m、地面 ε=15 与 σ=0.005 S/m、大陆温带气候、mdvarx=11、可靠度 90%。**S**

公里与兆赫口径下自由空间损耗为 `20log10(d_km) + 20log10(f_MHz) + 32.44`，总损耗为 `FSPL + avar`，其中 `avar` 返回所请求分位的总衰减量。平坦地形回归必须复现两径地面反射模型。**S**

### II-C-2 时间维：链路好坏的时间相关结构

用 Gilbert-Elliott 两态模型，参数由 ChirpBox 真实 LoRa 轨迹拟合：20,913 个逐小时快照、21 节点、420 条有向链路、878 万次状态转移，得 `p(g→b)=0.0712`、`p(b→g)=0.1567`，链路可用率 68.75%。平均下行突发 6.38 h，上行突发 14.04 h。同丢失率下 i.i.d. 模型只预测 1.45 h，相差 4.4 倍。**F**

中断时长不是指数分布。42.99 万个未删失中断段的经验分位数为：中位 2 h、p90 5 h、p95 10 h、p99 42 h，1.8% 超过 24 h。对数正态（$\mu=0.919$、$\sigma=0.807$）在 AIC 与 KS 距离上最优，指数被拒绝。样本量 43 万时 KS 检验对所有参数化模型都给出零 p 值，因此建模时以经验分位数为准，对数正态仅作平滑内插。**F**

ChirpBox 采自上海城区。借用的是时间相关结构，不是绝对水平。**效力威胁**

### II-C-3 地形考虑

本节是本文与同域文献的主要分野。对 9 篇近期 JSAC/TCOM/TWC/TMC/TVT 同域论文的通读显示：**没有一篇使用 DEM、地形数据库或实测信道 trace 来论证仿真真实性**。地形最多作为几何抽象出现（一个环形部署廊道），多数完全缺席；3GPP TR 38.901 参数表的使用为 0 篇。

真实地形给出的结果与距离主导的直觉相反。**M**

| 节点 | 距离 | 遮挡高度 | 自由空间损耗 | L50 总损耗 |
|---|---|---|---|---|
| valley A | 8.37 km | 1169 m | 109.7 dB | 217.0 dB |
| far E | 12.61 km | 1102 m | 113.2 dB | 201.2 dB |

距离近 4.2 km 的点位反而差 15.8 dB。遮挡造成的超额损耗在 71 至 107 dB 量级，而 SF 从 7 提到 12 只增加 14 dB 灵敏度，链路自适应因此无法救回被地形挡住的节点。

单网关在 121×121 网格上的可达点仅 1689 个，占 11.5%；连不通的 12952 个，占 88.5%。可达点损耗中位数 113.4 dB，不可达点中位数 206.6 dB。**M**

独立做的几何视线判定给出同一量级的结果：原生分辨率下仅 6.6% 的格点与网关有清晰视线。

几何判定采用 DEM 剖面加第一菲涅尔区净空判据，形式为：$r_n=\sqrt{n\lambda d_1d_2/(d_1+d_2)}$，逐点遮挡度 $\text{occupancy}_i = (\text{elev}_i - f_{\text{bottom},i})/(\text{LoS}_i - f_{\text{bottom},i})$，地形高于视线记 100%，全路径取最大遮挡度，**判据为净空不低于 60%**。该判据在 12 个山区与平坦场景中与实测连通性 100% 一致，而不含地形的 log-normal shadowing 基线只有 50%（Torres-Sanz 等, *Internet of Things* 38:102012, 2026, FresSim）。**S/M**

该文献同时给出一个可用的验证靶子：6 个端节点距网关 190、250、500、620、2200、3200 m，网关海拔 1295 m、节点 1285–1385 m，需复现三个定性结论——2200 与 3200 m 的山区链路不通、平坦地形通、以及超长距 28 km 场景可通。本地形模块的验收标准即复现这三条。**S**

地形的影响量级另有独立证据：相对平坦环境，地形导致成功接收包数下降 58.63%（Torres-Sanz 等, ACM MSWiM 2023, `10.1145/3616388.3617530`）。**S**

## II-D 能量模型

高海拔站点的失效由供电而非无线决定。

储能取 LiFePO4：−20 °C 下可用容量约为标称值的 50%，低于 +5 °C 无法充电。**S/M** 发电取光伏，气温基线由海拔推导：3925 m 处 1 月均温约 −19.5 °C、7 月约 −7.5 °C，日间温度全年低于充电下限。

三条反直觉结论。面板从 30 W 增到 200 W，停电率恒为 93.7%，发电被温度闸门掐死而非被能量禀赋限制。积雪掩埋的概率从 0 扫到 0.20 每天，停电率不动，因为它在充电闸门打开之前不构成约束。杠杆只有电池化学、加热电池箱，或降低站点海拔。**M（模型输出）**

器件级能耗账本取实测剖面：活跃平均 35.7 mA、待机 16 µA，单周期活跃窗口约 15 s、休眠 3585 s，周期耗电 0.148 mAh、日均 3.56 mAh、全年约 1300 mAh，无光照条件下约 2.8 年。该组数据由 INA229 电流监测实测得到（Ragnoli 等, *JLPEA* 12(3):47, 2022）。**M**

对照区间：ESP32 深睡 10 µA、SX1276 深睡 0.2 µA、SX1276 发射 120 mA，配 2600 mAh Li-ion 时最坏全开约 16.3 h、深睡约 13.5 年（Pires & Veiga, *Designs* 9(6):144, 2025）。两个区间相差两个数量级，说明寿命对占空比的敏感性远高于对器件的敏感性。**M**

气候基线整体平移 ±6 °C，停电天数在 342 天附近不变，只有夏季均温升到 0 °C 以上才改善至 217 至 260 天。基线可能偏冷约 10 °C。**效力威胁**

## II-E 业务与队列

上行为周期性遥测。监测对象含降雨、孔压、水位、地表位移与裂缝开度。实体部署给出的间隔为：贵州水城滑坡监测系统定时回传 **1 h**（连续运行 9 个月），触发加密采集时 **5 min 一次、每次 3 包**（Wang 等, *Frontiers in Earth Science* 10:899509, 2022）；意大利 Pantelleria 系统发射间隔 **60 min**、载荷 **38 B**（Ragnoli 等, *JLPEA* 12(3):47, 2022）；Hochvogel 高山岩土监测 **10 min** 一次、连续运行超过 5 年（Leinauer & Krabtlatter, EGU25-11121, 2025）。本文取 10 min 与 1 h 两档并扫描。**M**

## II-F 失效与中断模型

本节是本文的第二处分野：9 篇同域论文无一设立失效与中断模型小节，中断在多数工作中是参数扫描的一个维度而非被建模的过程。

单个实体在时间轴上经历上线、可用、退化、掉线、恢复。对节点而言，掉线有两个独立来源，且**观测端不可区分、处置方式完全不同**：

**持续遮挡。** 由地形与传播决定，任何自适应与重传都无法挽回。占比 88.5% 的格点属此类。处置只能改架构：换位置、加中继、走中继回传。单网关加一个最优中继后覆盖升至 33.2%，中继有效但远不足以闭合。

**季节性静默。** 由能量与温度决定，冬季长静默、夏季恢复。处置是等待或加热。

现有工作普遍把两者当作同一件事，其后果是：把永久失效算作可恢复故障会高估恢复策略的价值，把季节性静默算作随机丢包会低估所需的缓冲深度。

变动的时间尺度由三处决定，彼此相差三个数量级：空间维给出 11.5% 随时可通与 88.5% 永久不可通；时间维给出 6.38 h 的平均中断突发与 42 h 的 p99 尾部；能量维给出以月计的冬季静默。任何单一尺度的评测都会漏掉另两个。

**agent 的观测模型。** 上述过程是物理真值。agent 看到的是它的调用结果，而调用穿过同一条链路，因此观测是物理过程经一次有损、有延迟、可能重复的投影。形式化地说，agent 在时刻 $t$ 对实体 $e$ 的动作 $a$ 得到的观测 $o_t(e,a)$ 取值于 {完成并回执, 未完成, 结果不可知}, 其中"结果不可知"混合了三种物理原因：请求未达、实体已失效、回执丢失。**agent 无法在单次观测内区分这三者**，只能通过后续调用的时序模式逐步排除。这一投影是本文与"假设状态可观测"的既有工作的根本差别。

## II-G agent 模型

### II-G-1 状态与知识

agent 维护任务集与每个实体的本地信念。信念不等于真值：它记录上一次成功观测的时刻、上一次尝试的结果、以及尚未结算的动作。**结果不可知的动作必须保留在未结算集合中**，不能因为超时而删除——删除即意味着此后可能对同一逻辑写重复执行。

### II-G-2 动作空间

对某实体下发某个带类型的 capability 调用、等待、重试、改走另一实体、放弃并上报。capability 分只读与改状态两类，改状态的动作不幂等，除非远端对同一逻辑写做去重。

### II-G-3 执行语义

一次能力调用不是一次函数调用，而是一个生命周期：下发、执行、回执，三段各自可能丢失。因此 agent 必须区分"超时"（我方停止等待）与"结果不可知"（认知状态），前者是策略，后者是事实。这个区分是 II-H 中成对指标的依据。

### II-G-4 目标

在给定能量与频谱预算下最大化任务存续。目标函数不写成抽象的"存续"，而写成 II-H 的可观测量，因为只有可观测量才能被评测，也只有可观测量才能暴露策略之间的取舍。

### II-G-5 与既有工作的层级关系

同类工作中 agent 或控制器的作用是**组合与恢复**：在给定的实体选项池中选择、切换、恢复。本文的自变量是**池本身在变**，agent 要从变动中维持任务的存续。前者的失败模式是选错，后者的失败模式是不知道自己面对的是哪一种失效。

## II-H 指标

| 指标 | 定义 | 说明 |
|---|---|---|
| 到报率 | 周期内应到达的采样包中最终到达的比例 | 按传感器与按时间分别统计，单一全局值会掩盖局部失效 |
| 到达时延分布 | 每包从生成到到达的时间，报分位数 | 均值被少数快包主导，监测关心尾部 |
| 能量预算余量 | 剩余能量相对越冬所需的比例 | 决定下一冬季是否存活 |
| 重复执行次数 | 同一逻辑命令被实际应用超过一次的次数 | 与任务正确性正交的执行正确性 |
| 零执行周期 | 应下发但最终未落地的命令数 | 与上一行方向相反，必须同时报 |

最后两行构成一对。只报其一会奖励错误行为：放弃执行可以压低重复率，重发可以压低零执行数。实测证据见 `docs/s5-benchmark/s6-11-execution-layer-results.md`，其中 `verified_wrapper` 把重复减半的代价是 562 个周期完全未执行。

**报告口径。** 到报率按三档时间分辨率分别报告，口径取自 Hochvogel 高山监测的实测做法：日均（当日至少 1 个测值即算有效）、时均、以及全部原始采样。该实测显示三档差异极大——日均可靠率 97.3–100%，时均裂缝计 96.7–99.4%，而激光测距仪只有 56–65%（每年被雪覆盖数月）。只报日均会把一个半数时间失效的传感器呈现为近乎满分。**M**

**命名说明。** 同域文献中不存在任务级可靠性的公认指标名。可靠性普遍写作链路级的 coverage/outage probability，或服务级的 availability/feasibility rate。本文的到报率与零执行周期属任务级指标，需在首次出现处给出定义式并论证其必要性。

## II-I 仿真方法

按同类文献惯例报告 Monte Carlo 次数并在图题区分解析值与仿真值。本文的解析成分有限，结果以仿真为主，须逐图标注运行次数与随机种子。

传播模型按**三档递增真实度**组织并逐档量化增益：自由空间 → 加 DEM 视线遮挡 → 加刃峰绕射。这一叙事结构是同类文献的既有做法，本文沿用并把"只按距离"作为最低档对照，量化地形建模本身带来的差异。**S**

## 对照方案

按同类文献的句式组织，每条声明来源与实现方式。通读显示，9 篇中运行第三方公开实现的为 0 篇，6 篇以重实现或自建方式构造对照，本文沿用此惯例并公开代码。

"We consider the following schemes":

1. **单跳直连（退化消融）**：节点直接与网关通信，无中继、无 store-and-forward。给出无架构增益的下界。
2. **固定门限策略**：按静态阈值决定是否重传或切换，不感知链路时间相关性。工程惯例。
3. **ADR / 链路自适应**：依 RSSI 调 SF 与发射功率。出处 Reynders, Meert, Pollin, ICC 2017, `10.1109/icc.2017.7996380`。隐含假设是链路存在，只需调参；II-C-3 的结果说明该假设在 88.5% 的格点上不成立。
4. **DTN store-and-forward**：Fall, SIGCOMM 2003, `10.1145/863956.863960`。接触机会到来即转发；对应到本文场景需改为固定节点加 UAV 过顶计划，直接套用会高估投递率。
5. **集中式 oracle**：已知全部链路未来状态的上界，用于量化在线决策的差距。
6. **无地形版本（本文消融）**：把 II-C-1 换成对数距离路损，其余不变，用于量化地形与失效建模带来的差异。

前五条为对照，第六条为自有消融。
