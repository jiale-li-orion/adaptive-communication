# 覆盖增强与地形传播：增量证据与空白（RIS / ITM / 射线追踪 / 数字孪生）

> 来源：2026-09-13 检索。所有 DOI 经 Crossref 逐条解析；原如未能取得全文的，标 `仅题录`。
> 本文件回答两个问题：**"信号增强覆盖"有没有可用手段**，以及**本文地表-传播这一层的定位缺口在哪**。

## 1. RIS（可重构智能表面）用于地形遮挡覆盖增强 —— 判定：**不可用**

**结论：RIS 的室外实测存在，但"山区地形遮挡"尺度上的实测基本不存在；且距离尺度差 1–2 个数量级。**

### 1.1 有什么

| 层级 | 状态 |
|---|---|
| 微波暗室 / 室内 NLOS 实测 | 多篇，最高增益约 40 dB（Rains 2023） |
| 室外实测（5.8 / 2.6 / 3.4 / 4.9 GHz） | 多篇，含地下车库、河岸道路、**山地隧道**；室外增益 >35 dB（Pei 2023） |
| 最远室外链路 | **500 m**（Pei 2021，视距/短距），约 1 W 功耗 |
| 真实 5G 商用网大规模试验 | 重庆，2.6 GHz（512 单元）+ 4.9 GHz（1024 单元），覆盖 8 类场景（含山地隧道、跨江桥梁、河岸道路）；实测 6.14 dB（RSS）/ 351%（信道质量）/ 89%（上行吞吐） |

### 1.2 没什么（关键否定性证据）

1. **山区/野外监测尺度的 RIS 实测完全缺失。** 唯一沾"山区"的实测是**城市尺度商用网补盲**，不是"无电网、无回传、链路 1–20 km"的地质监测场景。
2. **距离尺度不匹配。** 现有室外 RIS 实测最远 500 m 视距；山区监测典型需求 1–20 km 且以非视距/绕射为主。RIS 有效口径随距离平方增长，sub-6 GHz 下对公里级链路所需口径与功率不现实——**该物理约束在文献中既未被实测证实也未被证伪**。
3. **增益随级联递减已被实测**：四跳中 RIS#4 几乎无贡献，四 RIS 替代单 RIS 仅得 0.9 dB（理论应为 6 dB），原因是前级反射功率受限。
4. **RIS 与 LPWAN 的结合零实测。** RIS 单元尺寸 ∝ λ/2，在 868/915 MHz 约 16 cm，**大口径 RIS 在 LPWAN 频段的野外实测为零**。
5. **长期运行可靠性空白。** 所有 RIS 实测均为短时 campaign，**没有任何一篇报告 RIS 户外连续运行数月/数年的可靠性，或积尘/覆冰/风雪对相位精度的影响**——而这恰是灾前长期监测的核心关切。
6. **无地形感知的增益预测模型。** 重庆试验给的是"某场景提升多少 dB"的黑箱实测值，没有可迁移到其它山谷/坡向/植被条件的模型。

> **一句可写进论文的话**：在本文场景（无市电、无回传、1–20 km、以绕射为主、需连续运行数年）中，RIS 既缺少尺度匹配的实测证据，也缺少长期可靠性证据，因此**不作为候选手段**。

> ⚠️ **引用纪律**：Xiong et al.（arXiv:2303.03287）是常被当作"野外 RIS 试验"引用的工作，但对该文全文做关键词计数扫描的结果是 `mountain` **0** 次、`terrain` **0** 次、`hill` **0** 次、`elevation` **0** 次；其场景为微波暗室（5.8 GHz）、地下停车库（3.4 GHz）、120 m 室外步道。**它不构成"地形遮挡实测"证据。**

## 2. ITM（Longley-Rice）的现代使用与误差标定

**已解决：**

- **实现齐备、许可清晰**：NTIA `itm` C++ v1.3（README 声明与 Fortran v1.2.2 功能等价，覆盖 20 MHz–20 GHz）、Fortran 归档、Python `itmlogic`（**LICENSE 为 MIT**）。`itmlogic` 本身是 JOSS 同行评审软件论文，DOI [10.21105/joss.02266](https://doi.org/10.21105/joss.02266)。
- **仍被主动使用且方向一致**：2010–2021 年间至少 5 组独立团队（TV 广播、铁路、频谱工程 SEAMCAT、组合模型、5G 成本评估）持续使用；ITM 仍被 MNO 广泛用于 *long-term median transmission loss*。
- **误差量级有实测标定**：URSI 2015 给出 **均值 −1.4 dB、SD 8.4 dB**（13 个测点，44.6–139 km），并指出 ITM 在**大障碍与阴影区（即山地特征）偏悲观**；另有工作指出 ITM+DEM 比 ITU-R P.1546 与 Hata-Davidson 更接近实测（P.1546 在 >50 km 平均低估）。
- **数值稳定性已检验**：用真实 Colorado DEM 做多精度移植实验，确认 single/double 精度稳定，仅极少数情形偏差 >3 dB；half-precision 失效。
- **DEM + 第一菲涅尔净空法在 LoRa 场景已被实测验证**：FresSim 12 场景 100% 一致，不含地形的 LoRaSim 仅 50%（DOI [10.1016/j.iot.2026.102012](https://doi.org/10.1016/j.iot.2026.102012)）。
- **LoS 与 Fresnel 的量级差已被量化**：同一发射机覆盖率 **33.96%（LoS）→ 22.98%（2D Fresnel）→ 19.19%（3D Fresnel）**；并证明**低分辨率地形数据无法辨识植被**（DOI [10.3390/ijgi7080322](https://doi.org/10.3390/ijgi7080322)）。

**未解决（对本文有效力威胁）：**

- **ITM 从未被用于 LPWAN（LoRa / NB-IoT / Sigfox）链路预算的实测标定。** 命中 ITM 的全部是 VHF/UHF 广播、铁路、雷达、频谱工程，**LPWAN 侧 0 条**——LPWAN 一律用 log-distance / CI / FI / Fresnel 几何法。

  → **这对本文是双面的**：既是可主张的定位缺口（G3），也意味着**本文用 ITM 跑 LPWAN 没有同行先例可对标**，审稿人可能要求说明适用性外推的依据。ITM 的 20 MHz 下限覆盖 433/868/915 MHz，且其 point-to-point 模式带 `climate` / `N_0` 参数、输出可用性分位（CDF），**方法上适配，但需在论文中论证**。
- **2015 年之后没有带 RMSE 的 ITM 山区实测标定**。最新的带数字结果仍是 URSI 2015。

## 3. 射线追踪（RT）

- **误差量级已被近期大规模路测量化**：27 GHz 城市 14,725 点，**RMSE/MAE 10–12 dB**，且 **Sionna 系统性高估功率**；建筑边界外扩可把平均误差从 1.9 dB 降到 0.75 dB（DOI [10.3390/telecom6020026](https://doi.org/10.3390/telecom6020026)）。
- **不做实测标定会直接失效**：AIRMap 在 Colosseum 上报告 *"Both the Ray Tracing and Uncalibrated U-Net models failed to establish a connection"*，标定后 RMSE 8.86 dBm（[arXiv:2511.05522](https://arxiv.org/abs/2511.05522)）。**这是"必须实测标定"的最硬证据**——本文若不引入实测，把 Sionna RT 当作"更高真实度"的第三档会遇到同一质疑。
- **许可与接入**：Sionna / Sionna RT 为 **Apache-2.0**；Sionna RT 已于 2025-02 拆为独立仓库；存在 `tkn-tub/ns3sionna` 可把 RT 信道接入 ns-3。
- **RT 论文普遍主动排除季节与植被**：多篇明说晴天测量、场景无植被。

## 4. 空白清单（可直接用作论文定位缺口）

| # | 空白 | 证据锚点 |
|---|---|---|
| **G1** | **"DEM 地形 × 长期季节变化（积雪/植被）× 数月–数年链路可用性预测"完全无人做**——本主题最强、最可主张的空白 | 各数据集工作全不引 DEM；地形类工作全是静态快照；RT 类工作主动排除季节与植被 |
| **G2** | **把积雪作为"有效地形剖面的几何变化"来建模**：高山实测已证明雪埋可使可靠率从 97%+ 掉到 56–65%，但**无人把雪深映射为有效地形剖面/有效天线高度的增量再跑 Fresnel 或 ITM 判据** | Hochvogel 实测 + 现成的几何判据 |
| **G3** | **ITM 用于 LPWAN 山地链路**：ITM 的 20 MHz 下限覆盖 433/868/915 MHz，其可靠性分位输出天然适合"长期可用性"，但**没有任何 LPWAN 论文用过它** | 见 §2 |
| **G4** | **真实 DEM 山地地形的射线追踪缺少实测校验** | §3 |
| **G5** | **非城市/山区无线网络数字孪生缺位**：现有数字孪生要么是流量层，要么是城市建筑几何层 | 检索面不重叠 |
| **G6** | **2015 年之后无带 RMSE 的 ITM 山区实测标定** | §2 |
| **G7** | **植被的季节性损耗模型未与 GIS/DEM 植被层耦合**：ISPRS 已证明高分辨率 DSM 可辨识植被，但用的是**单一时刻** DSM，其作者本人把"考虑植被的可见性分析"列为未来工作 | DOI [10.3390/ijgi7080322](https://doi.org/10.3390/ijgi7080322) |
| **G8** | **RT 与 ITM / Fresnel 几何法在同一山地场景下的交叉对比不存在**：两条方法线互不引用、互不比较 | §3 vs §2 |

> **G1 与 G2 是本文差异化最有力的支撑**：它们把"地形建模"从"我们用了真实 DEM"（不构成通信贡献，Astra 的批评成立）升级为"**我们首次把季节性地形变化纳入链路可用性预测**"。这是可以被审稿人接受的通信侧问题，而不是工程实现细节。
