## 7. 结论：材料里最强的、能支撑"中心必须对现场设备做远程控制且通信机会稀缺"的一手证据

材料里**没有任何单一文件**同时证明这两件事，最强的一手证据是一条**由四份一手文件首尾相接组成的链条**，其中承重的一环是：**重庆市规划和自然资源局公开的群测群防智能化监测预警设备通信材料**（PDF 印刷页 10–11，`S2/pre:40`）——它是材料中唯一一份**政府公开的、定义了中心侧对野外设备读写"上报周期 `0042`／采样间隔 `0045`／通信模式 `00D0`"的正式技术文件**，并以"带序列号及回复机制"证明下行的确认语义在行业内是既成事实，因此"远程控制"不是外部想象而是现网既有接口；与之配套的规范性证据是**广东省《地质灾害自动化监测规范》地方标准草案 11.3.1**（`S2/geo:303-307`），它以"**在供电和通信通道畅通时**"这一自认最可能不成立的前提条件、把验收下限只定在**在线率 ≥ 70 %**（而招标口径喊到 95 %，`S2/geo:284`、`S2/geo:326`），并在同一款里给出仿真可直接对齐的硬性时限——**现场采集至传输监控终端 ≤ 5 min、采集间隔 ≤ 120 min、缺失率 ≤ 3 %**；"机会稀缺"一侧则由**工信部联信管〔2024〕256号**（`S2/geo:106-134`、`S2/ann:434-485`）以"**断路、断电、断网**"为极端场景基准、把**北斗短报文与天通明确降为"基层保底"手段**来给出国家层面的承认，并由北斗民用标准产品"**单条 131 个汉字、最短发送间隔 120 秒**"（`S2/geo:229`）与 LoRaWAN Class A"**下行依赖上行后的接收窗口**"（`S2/pre:57`）给出可量化的机会上限。

这条链里最强的**单一文件**是 **256 号文**（政策原文、14 部门联署、gov.cn 全文可核），因为它是唯一一处国家层面**同时**承认通信在最坏情况下不可用、并把低带宽小数据卫星链路指定为保障底线的正式文本；而最强的**单一"远程控制"证据**则是**重庆市的设备通信材料**。必须同时记住它的边界：**"下发频率"本身在四份材料中一个数字也没有**，材料自己把它写进了"下一次与中通服交流最值得获取"的清单（`S2/pre:196`），并明确"当前没有报价及运维频率"（`S2/pre:172`）——因此任何引用"中心多久下一次命令"的说法，都必须以"材料未给出"作答，不得用项目内部演示假设（每小时→每五分钟，`S2/pre:99`）冒充真实运维频率。
