## 1. 结论先行

**H0：在这个被精确定义的"200 B 短报文开放世界装包"问题上，零样本 DeepSeek-flash 不产生被冻结强规则
吃不掉的残差。** 三档一致：

| 档 | edf | rule_linear | rule_keyword | rule_tree | **llm_flash** | oracle | LLM−该档最强规则 |
|---|---|---|---|---|---|---|---|
| R 负对照 | .771 | **1.000** | .996 | .996 | .958 | 1 | −.0417（输 linear，显著） |
| S seen | .650 | .764 | .934 | **.996** | .874 | 1 | −.1218（输 tree，显著） |
| H held | .669 | .839 | **.933** | .918 | .919 | 1 | **−.0139（输 keyword，显著）** |

H 档（唯一允许 agent 证明自己的格子）配对差 bootstrap+t 双检验 **CI=[−.021,−.0074] 排除 0、方向为负**，
追回份额 capture\*=−.195。**H1 的三条（显著为正、capture\*≥.5、再过 nonlinear）第一条就不满足，
按 04b §6 不触发 rule_nonlinear 第二闸门**。t=0.3 变异子集同向（Δ=−.0134），结论对采样温度鲁棒。

## 2. 规则侧：能力阶梯与任务有效性（gates 全绿）

`--rules-only`（零 LLM 成本）216/档、UNBAL=0：

* **R**：linear=1.000、keyword/tree≈.996 全部到顶，edf=.771 显著差 → **F1 通过**（真值=线性时规则到顶）。
* **S**：linear .764 < keyword .934 < **tree .996≈oracle**，oracle−tree gap=.004 → **F4 通过**：
  已知机理一旦由专家写成显式 if-then 即解，单信号关键词不够、加性线性更不够，阶梯成立。
* **H**：linear .839 < tree .918 < **keyword .933**，最强臂残差 .067；oracle−tree=.082∈[.05,.25] → **F4 通过**，
  held-out 组合确有规则残差。edf 显著低于 linear（Δ+.170）→ **F3 通过**，价值不等确实构成压力。
* **剂量反应（H 扫组合权重 α）**：α=0/.25/.5/.75 时 linear=1.000/.938/.839/.736、keyword=.986/.982/.933/.871。
  **价值越依赖语境组合，所有规则的残差越大**——任务难度横轴真实存在，只是 LLM 也没能沿这条轴追回。

## 3. 机制：LLM 输在哪（H 档分角色归因，`attribute_gate.py`，命中缓存无新调用）

| H 档指标 | linear | keyword | tree | **llm_flash** |
|---|---|---|---|---|
| hidden_residual 召回（oracle 选时也选） | 0/216 | 0/216 | 0/216 | **0/216** |
| distractor_lookalike 误选（oracle 不选却选） | 1.00 | 1.00 | **.042** | **1.00** |
| hidden_endo（seen 真临滑）召回 | .50 | 1.00 | ~1.00 | .87 |

机制三点：

1. **held-out 残差零召回。** "雨峰已过、隐患中等、速率仍低却持续加速的滞后蠕变"（hidden_residual），
   零样本下 keyword、已知机理树、**LLM 全部 0/216 召回**。LLM 与线性规则依赖同源的表层直觉
   （"高速率＋高隐患才危险"），没有自行做出"雨都停了还在加速＝内生失稳"的反直觉组合推断。
2. **被对抗迷惑项完全骗过。** lookalike 词面"加速＋隐患高"、实为与增强雨峰同相的雨驱虚高：
   LLM **100% 误选**，与单信号关键词相同；专家规则树靠显式"雨相位 AND/NOT"仅 4.2% 误选。
   **零样本语义理解在这个对抗构造上并不比单信号关键词更抗骗。**
3. **对已知真临滑的召回也不满。** seen 型 endo，LLM 在 H/S 档分别只召回 .87/.48，低于 keyword/tree。
   净效果：真信号没多抓、迷惑项照抓 → H 档净价值为负。

## 4. 稳健性与公平性自检（双向防 strawman）

* **t=0.3 变异（H，36 例）**：llm=.920 vs keyword=.934，Δ=−.0134、CI[−.029,+.0009]（小样本含 0），
  方向与量级同 t=0 全样本，**换采样不翻盘**；parse_fail=0。
* **规则侧做到最强（不立弱靶）**：对照不是单一线性规则，而是 linear→keyword→tree 能力阶梯，
  H 档动态锁定**实测最强的 keyword=.933** 当对手（04b §6），LLM 仍输。
* **LLM 侧不被做弱（不冤杀）**：(i) LLM 与规则**共用同一最优背包器**，只出每条重要性分、不手搓字节
  组合（04b §4 记录了手搓版会冤枉丢高分项的问题与修正）；(ii) 输入同源——每条数值事实都在文本里，
  不给规则额外信息；(iii) **零样本，prompt 只给任务定义，刻意不写"加速×非雨峰×隐患"判据**
  （写了等于把 rule_tree 喂给它）；(iv) 解析失败固定回退、不重试到对。
* **F2 的如实说明**：04b F2 要求 R 档 |Δ(llm−linear)|<.02 且 CI 含 0。实测 Δ=−.0417、CI 排 0，
  **字面不达标，但方向为负**——不是"LLM 在规则可解世界凭空赢"（那才会导致 INVALID），而是零样本 LLM
  在最简单的线性世界也只有 .958、存在约 4pp 的确定性缺口。它既排除了任务偏向 LLM，又额外佐证
  "零样本打分不具备冻结规则的确定性"。本 gate 不据此声明任何 agent 优势，H0 结论不受影响，此处留痕。

## 5. 为什么是 H0 而非"再换个强模型/调 prompt"

按预注册纪律，**不为救方法反挑阈值、不通过喂判据把 LLM 调成规则树**。下列方向若做，改变的是研究问题，
属下一阶段而非本批 scope（04 §5）：给 few-shot 领域示例或反馈学习（已非零样本）、换更强模型、
多机会动态重估、真实非结构化/含噪文本。本批只回答冻结的问题：**零样本、同信息、同背包器下，flash 能否
产生强规则吃不掉的残差——答案是否定的，且机制明确（held 残差零召回、对抗迷惑项零抗性）。**

## 6. 建构效度与局限（结果引用必须带上）

* hidden_residual 的"高真值"由生成器 combo 公式定义（内生加速不乘当前速率、隐患中等也计分）。
  其机理——降雨峰值过后位移仍加速的**滞后/残余蠕变**——在滑坡预警中有真实依据，但本实验是受控合成，
  **只支撑存在性与机制主张**：存在一类可精确定义的装包问题，其上零样本 LLM 未超最强冻结规则、
  且缺口随组合复杂度变化；**不**主张"真实地灾现场 LLM 必然不如规则"，更不写"首次/Agent 必要"。
* 模板化短句、字段齐全、无噪声，可能**高估** LLM（真实文本更脏更难，规则同样受影响，方向另议）；
  单模型 flash、零样本、单机会、成功率取 1、时延当拍、不计资费能量（同 03 §9 简化）。
* 成本：主跑 prompt 343,139 / completion 44,520 tok，t=0.3 子集 19,419/2,520，合计远低于 ¥2 闸门。

## 7. 对主线的意义：三链收敛到"intelligence 何时才有用"的边界

* 链 2a（v1.1/v1.2 minimal probe，`03`）：同权、公开期限、单资源下 **EDF 到顶**，"选哪几条义务"无智能残差。
* 链 2b（本 gate）：放开"价值不等＋需语境组合＋200 B 内容取舍"后，**已知机理专家规则到顶（S）；
  连 held-out 组合，零样本 LLM 也打不过最强冻结规则（H）**。
* 合起来给出 agent 不可替代所必须**同时**满足、而本动作面不满足的条件：价值不可被冻结规则表达、
  且信号不是零样本通用知识可反推、且需要跨机会演化或带示例/反馈学习。真正仍开放的格子被精确推到
  **非零样本（领域示例/在线学习）、多机会动态重估、真实脏文本**三处——这是路线 A 实证论文的 future work，
  而非继续在当前动作面找数值优势。**负结果在此闭环：它不是"agent 没用"，而是"agent 要有用必须先越过
  这些可检验的边界"，且在山区地灾＋北斗短报文这一现实动作面上，这些边界当前不成立。**
