# doc30 — J5-b 处置：chooser→access 耦合的发现，以及为何不做朴素离线最优

日期：2026-09-15　上游：doc29（J5-a 宽松上界）；结果 r18（本目录脚本 r18_*.py）

## §1 初衷
J5-a 给了无限容量机会上界（.966–.984），但 r900 仍有 .267 gap。原计划做"容量感知离线最优装包"紧上界，其前提是：**样本到网关时刻（heard）由接入段随机决定、与备份 chooser 无关**，这样可用一份固定 heard 输入离线求最优。

## §2 数据：前提不成立，且不成立的方式本身是机理证据
同 seed/档（r600/78）跑四个 chooser，按义务 oid 对齐 first_heard_at 的两两一致率：

| 配对 | heard 一致率 |
|---|---|
| latest vs cover | **0.997** |
| obligation vs cover/latest | 0.878 / 0.877 |
| edf vs 其余三者 | 0.805–0.866 |

样例：义务 n01:00073（release 43800/deadline 45000）在 cover/latest 下 43800 即听到，在 edf 下拖到 72600（已过 deadline）。

**两个结论：**
1. **cover 与最强 item 级基线 latest 的接入轨迹 99.7% 相同** ⇒ cover 对 latest 的优势是在近乎完全相同的输入下、纯由"包里装什么"带来的，比较极其干净，排除了"cover 靠改变上游接入而赢"的质疑。
2. **edf 的 heard 系统性更晚（约 20% 义务）**：EDF 式"先清最老样本"在过载下占着备份包位发老样本，经 primary pending 队列 / Class A 反馈使新样本的接入-上报也被拖慢，形成跨段正反馈（与 doc26/R13 的 EDF 过载崩溃同一条机理链，现在拿到了跨段证据）；obligation 因停发居中（.878）。

## §3 为什么不硬做数值离线最优
严格容量感知离线最优需要把"chooser 选择 → primary 队列变化 → Class A/接入反馈 → heard 变化"整个闭环离线化；若用单一固定 heard 输入求解，就对 edf/obligation 不成立（它们的 heard 被自己改变），得到的"上界"不可辩护。rows 只有义务级聚合（first_heard/n_heard），无样本级主/备交付标注，义务级 EDF 调度又无法对齐在线 svc 口径、且忽略一份样本覆盖多义务的红利，会产生不干净的数字。按"换两次通道仍不干净就不硬交付"的纪律，**不制造有瑕疵的紧上界**。

## §4 J5 的最终表述（写进论文）
- **J5-a 机会结构上界**：无限容量、真实稀疏机会网格 ⇒ .966–.984；主结果档 cover 距其上界 .049（r1200）/.078（r600）。
- **同输入纯净性**：cover 与 latest heard 99.7% 相同，cover 的增益是同输入下的装包增益（§2.1）。
- **r900 的 .267 gap**：该档容量仅产出 .46，每包已装满（9 条）、cover 发送量与 edf 相同而覆盖更多不同义务 ⇒ 主导因素是物理容量硬限；严格的闭环最优分解因 §2 耦合不可解耦，列为未来工作，**不声称 cover 最优**。
- 跨段反馈（§2.2）作为 EDF/obligation 失效的补充机理写入。

## §5 对主张的净影响
不削弱 Finding II，反而加强两点：(i) cover vs 最强基线是近乎同输入的纯净比较；(ii) item 级 EDF 的劣势有"装包顺序 + 跨段积压反馈"双重来源。论文无需紧上界即成立；上界用 J5-a + 同输入证据 + 物理容量论证三角支撑，措辞保持不声称最优。
