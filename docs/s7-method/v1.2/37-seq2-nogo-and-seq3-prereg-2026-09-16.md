## 0. 结论（先行）

在「单一升级片段、义务同质、密度可调、同构节点」的设定下，**候选 C 中"跨层联合数值优化"相对分离的强普通规则没有可测的按期交付增量**。按 doc33 预注册的关闭条件，**关闭"跨层联合调度作为方法贡献"这一候选**，不建联合优化运行时、不调参救结论、不换场景找增量。

这不是"整个 agentic 命题关闭"。被关闭的只是**资源数值优化**这一层；doc33 从一开始就把 agent 增量押在另一处（顺序3：真实 agent 工作流的执行接地可靠性）。顺序2 的 NO-GO 反而把这条边界划干净了：**机制内部不需要 LLM 的聪明，普通规则/MPC 已是最优工具；agent 的成败在问题构造、跨层修复选择与兑现反馈。**

## 1. NO-GO 的证据链

固定 seed 0、错位相位、solar .03、中断 h4–20、升级 600→300：

| 改动 | svc | missColl | missDeliv | dead | 解读 |
|---|---|---|---|---|---|
| dayfeed＋稀缺备份 r1200/78 | .357 | 2588 | 2282 | 0 | 基准（能量段已解） |
| 备份饱和 r120/78 | .549 | 2588 | 826 | 0 | 放宽回传，交付升、缺采不变 |
| 无中断、主路 p=.62 | .488 | 2059 | 1821 | 0 | 回传概率仍是约束 |
| 无中断＋主/接入完美 p=1 | .718 | 2136 | **0** | 0 | 回传缺失归零 |
| 饱和备份＋主路完美（采集/能量天花板） | .718 | 2136 | 0 | 0 | **再放宽回传也不动** |

**结构性理由（三者合起来封闭了联合空间）**：

1. **稀缺档备份是硬瓶颈且配额被用满**：r1200/78 全天 75 包全部发出、750 条记录，maxcov 在网关侧按义务级边际覆盖选包（R20 已证其为最强、不停发、阶段2补满）。网关候选样本始终过剩（600 密度 84/h ≫ 备份 27 rec/h），上游加密再多也不能突破配额。→ 下游"选包"不缺候选，上游联合加密不增加装包交付。
2. **接入衰减窗物理不可达，加密无效**：中断后期 h15–18 现场侧准时 heard=0（C0 共同事实，缓存积压＋备份极慢）。此窗内无论采集多密，样本赶不上义务 deadline，属物理不可兑现，不是控制耦合。
3. **剩余缺口在夜间能量，属 EH 采样传统优化**：回传完美后仍 missColl=2136、svc 封顶 .718，缺口是夜间无充电时 300 密采必死（.068 Wh>.05 Wh）、dayfeed 主动降疏所致。这是能量采集采样/传输优化（Bacinoglu 阈值、Zakeri POMDP 一脉）的教科书问题，确定性策略/MPC 是恰当工具，**不具 agentic 新颖性**。

即：最窄段在备份配额与接入（物理/资源），不在"采集决策 × 回传决策的耦合"；不存在 doc07 设想的"配额空闲却因上游没加密而无候选"的错配（已核对备份包无闲置、候选恒过剩）。**H1 若仅指"联合密度优化"，证伪。**

## 2. 这一负结果的可发表价值（不丢弃）

- 它给出任务变更下**普通自动化的能力边界与结构化不可兑现面**：哪些升级义务在给定能量/接入/回传下物理不可兑现、占多少（夜间 ~28%、中断窗 ~80%）。
- 它证明正确的工程结论是**编译为受约束的分段密度 + 义务级装包 + 显式不可兑现声明**，而不是"全量执行授权"（comply 致死，svc .21）或"无视授权"（ignore 错位 .28）。
- 静态选包证据（R20 Finding II）与本负结果共同构成论文的"通信执行层应向控制器暴露什么"的**需求来源**：义务级 deadline/覆盖、备份配额与已用量、配置生效时刻、接入可达性、未决物理后果。

## 3. 顺序3 预注册（真实 agent，命题主战场）

**待检验主张**：一个真实的、用自然语言接收会商授权并通过工具执行监测任务的 agent，在没有"执行接地编译/检查机制"时，会**自然地**（非手造）犯跨层执行错误；加入机制后，同模型、同信息、同工具预算下更可靠地形成并执行监测任务。机制内部的数值求解交给普通规则/MPC（顺序2 已证其最优），agent 不与之比优化。

**机制 M（候选 C 的真正形态）＝执行接地任务编译层**：
1. 义务链中间表示：监测义务→合格样本→到网关→截止前回传→中心完成证据，逐段可对账；
2. 可行性反例证书：计划不合法时指出"哪条义务、哪个时间区间、哪一段能力受限、改哪部分计划才可能改变结果"（能量/接入/回传配额/生效延迟）；
3. 未决物理后果簿记（H2）：在途命令及生效时刻、已采未传样本、已耗能源、已开窗未到期旧义务，任务变更时不全量重置；
4. 工具化求解：把 dayfeed/maxcov/EH 规则与一个滚动 MPC 包成 agent 可调用的工具；机制负责"何时调哪个、结果是否可兑现、如何向授权方反馈"。

**臂（同模型 deepseek-flash 优先，同信息、同工具预算）**：
- A0 通用工具循环 agent（ICG-Restore/OSS-GPT 风格反方）：给自然语言授权＋常规配置/选包工具，**不含**义务链反例与未决后果簿记；
- A1 同 agent ＋机制 M；
- 配两组链路：理想（可靠回传）与间歇（h4–20 中断＋弱能量），任务含一次升级与一次降级/解除（压 H1、H2）。

**指标（独立 scorer，业务为准）**：固定外部义务的按期交付、缺采、死亡/末电、真实空口/备份成本；**错误完成声明（声明兑现但未兑现）、不可兑现声明真伪（被拒但本可完成＝假阴性）、错误控制层修复次数（回传瓶颈却加密采样等）、未决后果丢失次数**。语言流畅度/格式/工具调用次数不计收益。

**晋级/关闭**：
- 若 A0 已自然可靠（很少跨层错误/虚假声明），或 A1 相对 A0 在业务指标与错误声明上无显著、可复现改善（多轨迹、留种子），则**关闭 agentic 机制主张**，论文写成"传统自动化＋边界刻画"的系统/测量论文（仍可投通信/网络实验类），不硬立 agent 贡献；
- 若 A1 在同能力下显著减少跨层错误与虚假声明、改善固定义务交付，且 A0（通用工具循环）做不到，则机制主张成立，进入顺序4（任务/相位/资源留出评测）与 LaTeX。
- 反方公平：A0 给同等工具与求解能力（可直接调 dayfeed/maxcov/MPC），只差"义务链反例/未决后果簿记"这一机制，避免 strawman；不手造 A0 的错误轨迹，错误必须由真实 agent 自然产生。

**新颖性风险（成稿前正面处理）**：ICG-Restore（意图对象/图检索/预算时间约束/候选检查/局部修复）、OSS-GPT（按接口文档编排真实网管 API）、IBN6G 已覆盖"自然语言→约束→工具编排"。本文差异化必须落在**间歇能量/链路上的物理兑现反馈**（义务链反例、生效延迟与未决后果、不可兑现声明的正确性），并在 related work 逐点区分；不称首次/空白。
