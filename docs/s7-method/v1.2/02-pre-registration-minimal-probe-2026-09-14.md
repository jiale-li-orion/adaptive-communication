## 1. 要回答的两个问题与**通过条件**（先写定）

| | 问题 | 通过条件 |
|---|---|---|
| **P‑A** | **actuator 本身有用吗**——用受限备用链路，能否明显好过「完全不用」？ | **最好的普通用法的策略**（§4 的 2–5）在**同种子配对**下，相对 `primary_only` 的**按时交付显著更高**（95% 区间排除 0），且效应量不低于「每条备用报文平均换回 ≥0.5 条义务」 |
| **P‑B** | **「选谁」这件事本身有内容吗**——在同一速率/容量限制下，不同选择规则会不会产生**实质性不同**的结果？ | 最差与最好的 chooser 之间的按时交付差**超过同种子配对区间**（即「选什么」不能随便选） |

**判定**

* **P‑A 不成立** ⇒ actuator 无价值 ⇒ **NO‑GO**，止步（不许再加复杂度去救它）。
* **P‑A 成立且 P‑B 不成立** ⇒ actuator 有价值但**没有分配问题**（就是一个 failover 通道）
  ⇒ 归为**传统通信问题**，**不接 Agent**。
* **P‑A 与 P‑B 都成立** ⇒ 存在真正的分配自由度 ⇒ 才允许进入 `structured baseline`
  （MPC/EDF/failover/DTN 能吃掉多少），再谈 `Agent gate`。

**⚠ 解读上限（2026-09-14 增补，写在跑之前）**：审计的第三条来源流已证明
**「稀缺机会里选谁」已有同行评议方法与真实系统**（北斗容量不足下的优先级装包；
SHETLAND-NET 的接触内分诊；CCSDS 的 overbooking management）。
因此 **即使 P‑A 与 P‑B 都成立，本轮结论只能限定为「本实例内存在分配自由度」**，
**不得**写成「首次提出」「新机制」或「Agent 有必要」；
它只能作为进入 `structured baseline`（MPC/EDF/failover/DTN 与上述文献方法能吃掉多少）
的**入场券**，而第 4 步的先验倾向于「会被吃掉 ⇒ 传统通信问题」。

---

**⚠ 与 v1.1 的关系**：这一切**不**推翻 v1.1 的任何结论。
v1.1 的结论是「**在旧动作面上** `delivered = 1[h* ≤ B(d)]` 且副本无关」；
本 probe 检验的是**换一个动作面**之后是否出现新的、后果不同的选择。

## 2. actuator 与参数（**每个数字标出处；派生量必须明示并做灵敏度**）

来源分两层（**互相独立取得，数值逐条一致**）：
**(i)** 我自己从 DZ/T 0460-2023 正文（41 页）与 DZ/T 0450-2023 正文（docx 预览）提取；
**(ii)** 独立来源流从**自然资源部官网报批稿 PDF**（`gi.mnr.gov.cn/202308/P020230818687468596923.pdf`）取得，
并给出**条文号**。两层的数值**逐条吻合** ⇒ 下表数值有交叉验证。

| 参数 | 取值 | 出处 | 级/状态 |
|---|---|---|---|
| **备用链路类型** | RNSS＋RDSS 短报文（区域）／低轨窄带卫星 | DZ/T 0450 **§7.4.2 / §7.4.3**；DZ/T 0460 §7.2 图 2 把卫星列为四类传输之一 | A |

| **时延** | RDSS 平均 **≤5 s**；低轨窄带平均 ≤5 s；Iridium <1 min | DZ/T 0450 §7.4.2/§7.4.3；Iridium 厂商 | A |
| **成功率** | RDSS **≥95%**；低轨窄带 **≥99%** | DZ/T 0450 §7.4.2/§7.4.3 | A；**本轮取 1.0（不计随机失败）并单列这一简化** |
| **功率** | 模组 ≤1 W（可按下行自适应、1 dB 步进）；休眠 ≤5 mW；发射 ≤5 W；灵敏度 ≥−130 dBm | DZ/T 0450 §7.4.3 | A；**能量不进本轮判定** |
| **场景依据（双模）** | 「地面公用网络信号覆盖不佳、地质灾害危险等级较高与极端天气事件易发地区，**应**采用地面公用网络与卫星通信相结合的双模通信方式」 | **DZ/T 0460-2023 §5.3.7** | A（**注意：双模要求的出处是 DZ/T 0460，不是 DZ/T 0450**） |

**⚠ 三方交叉核对后必须写下的两处精确化**

1. **双模要求的出处**：**DZ/T 0460-2023 §5.3.7**（用「应」，且限定条件正是本场景）。
   **DZ/T 0450-2023 §6.3.3.1 只要求**「通信模块应**至少**支持自组网或者运营商网络中的**一种**」，
   其冗余条款讲的是「双基站互为备份／多个网关接入点」，**不是第二条回传**。
   ⇒ **两条标准不得混用**；「dualmode 是国家标准强制」这句话的**唯一**出处是 DZ/T 0460 §5.3.7。
2. **本轮取用的工作点**：`速率 = 120 s/条`（民用二级卡与采购实配）、`容量 = K 条样本/包`，
   并在 **速率 ∈ {30, 60, 120, 300} s × K ∈ {1, 4, 9, 16}** 上做灵敏度；
   **结论不得依赖任何一个单点取值**。
   （**30 s 的依据**：官方服务规范 BDS‑OS‑PS‑3.0 表 7‑1 的**服务频度「平均 1 次/30 秒」**，
   且该表明确「用户实际服务频度、单次报文最大长度**根据注册参数约束**」⇒ **速率是配置量**，
   扫描必须覆盖官能力／标准下界／实配／旧卡四档。）

3. **⚠ 最大设计风险（先写定，必须随结果报告）**：**决策所需的状态量在现实中不可观测**——
   最终版来源流确认：**没有任何来源暴露「剩余配额」或「下一次机会」**，
   有文档的状态全是**链路级/二值**的（网络可用性、断网监控、自动重拨重连、发送成功判断、自检上报）。
   ⇒ v1.2 的义务级/机会级状态**必须由我们自定义**；**即使 P‑A/P‑B 成立，
   结论的可迁移性也受此限制**，不得写成「现场已有的策略」。**

**⚠ 仍然不许含糊的地方**

0. **义务期限不是标准导出的**：两条标准**都没有规定「从降雨到中心的端到端期限」**
   （只有「第一时间」「秒级」这类**无数字**表述）。因此本 probe 的 `d`、`grace` 与义务节奏
   **沿用 v1.1 的合成定义**（900 s 义务窗 + 一个周期宽限），**不得**声称它们是标准或现场要求。
   这也意味着：**本 probe 关于「按时」的结论只在该合成期限下成立。**
1. **每包能装几条样本 = 派生量，不是来源给的数**。来源给的是**字节/比特容量**
   （≤200 B 或 1835 bit）与报文格式（协议头 2 B、设备 ID n、数据包总数及序号 2 B、时间 10 B、
   每节点数据 n B、校验 2 B）。我按**自己的**字节账（200 − 16 字节固定开销、每样本约 20 字节）
   派生 **K ≈ 9**，并靠 §上 的灵敏度扫描兜底。
2. **能量不进本轮判定**（标准只给功率上限，每报文能量要自己乘时长 = 派生）。
3. **资费仍未取得**（三条独立来源流一致确认：标准与部署报告中**没有任何货币配额/资费**；
   「卡片工本费 35 元/张」来自自媒体，**D 级，不采信**）
   ⇒ **按条计费/包月配额在本轮不是成本轴**，成本轴只有**报文条数**。

**简化声明（必须随结果一起报告）**：成功率取 1.0、时延视作当拍、不计分包开销、不计资费。

**可观测性证据（⚠ 已收窄：**只**覆盖链路级/二值状态）**：真实 RTU/模块侧已有
**自检上报**（电池电压、充电电压、气压、温湿度、**信号强度**、位置）、**盲点补传**（自动判断发送是否成功）、
**阈值触发立即上报**、**远程参数配置/召测/升级**；标准侧要求**数据缓存至少保存 7 天**。
⇒ 「决策前可合法观测的状态」**是可实现的**，不是假设；但**义务级**可观测量仍须 v1.2 自行定义。

## 4. 臂集合（冻结，6 条）

| 臂 | 是什么 | 用不用 actuator |
|---|---|---|
| `primary_only` | 只用 primary；主链路不可用就等 | ✗（P‑A 的对照） |
| `backup_all` | 备用可用时**把当下所有待发数据都塞进每一条报文**（速率上限内尽可能发） | ✓ 最强的「不挑」用法 |
| `backup_fifo` | 备用可用时按**到达顺序**装满一条报文 | ✓ 普通 |
| `backup_latest` | 只发**最新**的样本（盲目轮询/最新优先） | ✓ 普通 |
| `backup_edf` | 按**截止期最近优先**装包（成熟 deadline‑aware 规则） | ✓ 强普通 |
| `backup_opportunity` | 按「**主链路的最后一次可回传机会是否已经错过**」＋剩余余量排序装包 | ✓ 本轮的候选 |

**全部 6 条臂共享**：同一实例、同一动作面（都是「装哪几条进这一条报文」）、
同一速率上限（1 条/60 s）、同一容量（K 条/包）、同一可观测集合
（**只用当时合法历史**：主链路是否可用、自己的待发队列、义务的公开期限；**不读环境真值、不读未来**）。

**⚠ 必须注意的一个不对称**：`primary_only` 与其余 5 条**动作面不同**（前者没有备用可用）。
所以 P‑A 是**跨动作面**的比较（这正是它要回答的问题），而 P‑B 是**同动作面内**的比较。

## 5. 指标（分列，不合成单一分数）

按时交付（`received_on_time`）、缺采、缺送、**发出的备用报文条数**、
**每条备用报文换回的按时交付数**、未交付义务里「差 ≤1 个上报档位」的条数。
判定用**同种子配对差 + 自助区间**；**单种子不得下结论**。
