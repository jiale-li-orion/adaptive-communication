## 0. 一句话突破口

**把研究对象从"agent 能不能判断哪条信息更重要"（语义层）整体上移到"在反馈被中断撕裂、控制
延迟生效、控制与数据争抢同一稀少双向机会、接入与主备回传分离的系统里，如何持续维持每条监测
义务的端到端可交付"（通信执行闭环层）。** v1.1 能改数据何时到网关却不能调度下游回传；v1.2 能
调度备用发送却把数据到达固定成 local 台账——**这个联合面从未被测过**。第一阶交付的是通信执行层
机制（规则/MPC 实现也算贡献，不要求 LLM 不可替代）；agent 作为该执行层在非平稳/模型错配下的一种
planner，第二阶在**同一合法信息、同一预算**下再比。场景不换（灾前山区、Class A、网关现场自治、
间歇回传、供电受限），并且因为研究对象纯是通信交付、地学风险判断留在节点本地自治，**从根上绕开
了 C3 的同信息、地学真值两条致命批评**。

## 2. 为什么联合面是真问题：四个场景硬结构（也是 novelty wedge）

联合不是"把两个已解决子问题拼起来"这么简单，关键在**耦合方向是双向且带延迟的**。对义务 i 区分
`H_i(a_up)` 受上游配置影响的就绪时间、`T_i(a_send)` 下游主/备发送时间、期限 `d_i`，有用路径
`H_i ≤ T_i ≤ d_i`。解耦策略的两类系统性次优：

- **回传中断、接入背压误放慢**：主回传断时，上游若按"回传堵→放慢上报"的本地背压动作，数据就绪被
  推迟；等备用发送窗口出现，池里没有"已就绪且在期限内"的货——**有发送机会却无货可发**。
- **盲目加速白耗电**：反过来持续加快上报，多采多发的数据若撞不上可交付机会，只在供电受限下空耗能量。

即**上游动作的价值要按端到端可交付概率评估，发送计划的可行性取决于数据就绪与配置生效时间**。
这四点全部来自参考部署的硬结构，且每一点都能做消融证伪：

- **W1 远端、延迟、可能永久不生效的控制**：`set_monitoring_profile/report_period` 要借节点下一次上行
  打开的 Class A 接收窗下发、再等下一个采样周期才生效。`runtime/operations.py` 的 outcome 可永久
  unknown；`monitoring/policies.py` 明写 "a downlink needs an opportunity, and an opportunity comes
  from an uplink"（DWELL 300s、命令 TTL 6h）。**对照 Zakeri（2311.06522）：其为发送端本地控制器、
  动作即时生效、反馈即时无误。**
- **W2 两段分离、异构的交付路径**：接入段（节点↔网关，间歇、Class A、LoRa 包 100 B）与回传段
  （网关↔中心，蜂窝主＋北斗 RDSS 备，速率/成本/机会特性不同）。**Zakeri 是单跳。**
- **W3 控制与数据争抢同一稀少双向机会**：一个接收窗既承载配置下发/回执又承载数据；读/写/传的竞争
  必须由报文与机会账本证明（task-contract v1.1 §7），不能假设健康旁路。
- **W4 受控且延迟的到达 × 稀疏发送机会的端到端耦合**：ICLDC（2504.14556）给了有界队列/外生到达/
  有限服务机会/接收反馈的**形式化（继承）**，但其到达是**外生给定**；这里到达被**远端延迟动作内生
  改变**——这是相对 ICLDC 的差。TopoLLM 一系（PS-UAV/LODA/WirelessAgent）让 agent 决定拓扑/UAV/
  带宽，属**灾后资源重规划**；ESWA-IIN/SCS-Lifeline 是工具编排的**恢复序列**。均非"长期灾前、跨
  采集—配置—回传、单义务端到端持续闭环"。

## 3. agent 如何诚实接回（第二阶，不是前提；规则获益不算失败）

1. **第一阶＝通信执行层**：delivery-aware 联合控制器（输出"现在维持哪档上报 / 是否用下行改配置 /
   本次主备窗口装哪些已就绪的货 / 收到反馈后是否重算"）。它是独立于 planner 的机制，规则或联合
   MPC 实现同样成立——这本身就是通信方法贡献。
2. **第二阶才比 planner**：在**同一执行层、同一合法可观测面（`interfaces.py` 的 ActionRecord/遥测
   便车状态、到达台账、截至 t 的链路二值历史、电量、在途配置版本）、同一机会与能量预算**下，比较
   规则 planner 与 tool-using agent。联合控制器需要在线估计未来就绪/机会分布、应对链路恢复非平稳
   与模型错配（地形/天气/老化漂移）、多义务多时间尺度取舍；规则 MPC 依赖正确且平稳的模型，agent
   是这类在线适配的**一种**候选。
3. 两种 planner 都获益 ⇒ 支持"通用通信执行层"；仅特定 agent 调用模式获益 ⇒ 必须给出该调用模式、
   有效指令语义与成熟设备管理基线（versioned_config / VTC）。**不再追求"传统方法无法表达"，也不把
   规则获益当成方法失败。** 这一步先不接 LLM（07 §7 一致）。

## 4. 节点规模回源结论（被点名"不确认"，已回 v1.1 源文件核实）

- task-contract-v1.1 **§3 原文**："5 台角色结构只限定 S1 实例。规模变化记录传感器数、网关数、测项、
  位置与拓扑，禁止用一个总数混合终端和网关。**16 或 32 均可作为 A 规模**"。即规范**未钉死唯一节点数**：
  - **5 台**＝S1 来源校验实例的角色结构（EI01 网关带雨量计 ＋ EI02–EI05 四个形变子节点），是唯一
    有现场论文角色依据的结构；
  - **16/32**＝目标参考部署 A 的**开放规模轴**，不是现场事实。
- `code/instance/deployment.py` 现状：两组 3×3 去中心环（各 8 测点）＝**16 坡面节点 ＋ 1 网关**；
  近坡正北 1.5km 8/8 通视，远坡东南 2.5km 仅 5/8（其余因 ±2m 扰动可达性翻转判 marginal 默认排除）。
  这是研究选择的 A 层几何，旧 D2"16 节点"虽被否、此处 16 来源不同，但**同样不能默认成既定前提**。
- **下一轮处理**：① 最小可证伪单元先用 **S1 的 5 台**把机制与判据跑通；② 再把
  `N∈{5,16,32} × 可达结构{全通视, 部分遮挡}` 当**解释变量**扫；③ 联合收益必须在**确实存在争用**
  的稀缺档检验（v1.2 主例 97% 非空机会一次装完、选择压力不足，是 07 §2.2 的有效批评），同时把
  "无争用档联合无收益"作为**负对照**如实报告；④ 备用额度终端级还是网关汇聚级必须在部署卡定死，
  **不得默认 16 节点共享一份备用包预算**（07 §3）。

## 5. 下一轮设计（A–D 具体化，先不接 LLM；预计 4–6h）

**A 自洽部署卡**（标准值 / 厂商值 / 研究假设三列分列）：选定单一制式与终端/汇聚结构；真实报文字段
与序列化长度（接入段 displacement 6B、rainfall 4B、LoRa 包 100B；北斗备用段单列）；发送周期与反馈
范围；能量口径（**未确认功耗不得用最大发射功率顶替**）。特别地：**200 B 属 DZ/T 0450 低轨窄带
卫星段 §7.4.3.2、≥1min 属卫星短报文段 §7.4.2.3，二者不拼成"同一北斗标准工作点"**（07 §3），保守
组合只能标为研究假设。

**B 三现成组合（不先造新策略）**，同部署同业务轨迹，保留无中断/接入中断/回传中断三态：
B1 `local＋自动备用`；B2 `冻结网格最强上报配置(config_grid_run 零件)＋自动备用`；
B3 `已有自适应上报(versioned_config/VTC＋节点本地自治)＋自动备用`。
指标：服务率、缺采、上/下行、空口、可核能量、备用包数与成本。**预算不足以争用时直接报"无选择
压力"，禁止改字节/效用公式造残差。**

**C 仅当 B 找到具体可改变的损失**，才加一条非预见联合决策参考（小实例枚举或合法信息下联合 MPC；
用未来真值的 oracle 只作诊断上界，不当可实现基线），并配两条消融：**只调上游 / 只调备用**。
**每个喂入控制器的信号必须过可辨识性门：置常数或随机打乱后，动作是否改变**——不改变就是死参数，
直接删除（这一条专门防 `_opportunity_score` 那种"分数在变、动作不变"的退化，07 §2.1）。

**D 逐义务反事实链 ＋ 关键证伪检验**：相同中断前状态下，证据→配置命令→Class A 实际生效→样本就绪
→主/备发送→交付账户全程对齐，服务与真实成本并列，报配对区间（新种子不当跨站泛化）。
**必做一次"控制延迟置 0 / 新鲜度拉满后联合增益是否消失"**：若消失 ⇒ 承重正来自 W1 延迟生效耦合，
坐实 novelty；若不消失 ⇒ 承重不在此，重新定位，不硬写。

**晋级判据（五条同时成立才继续，否则只关闭"联合"这一候选、不扩大成 agent 结论、不预承诺论文）**：
部署自洽 ＋ 合法动作能改变损失 ＋ 公平传统组合仍有差额 ＋ 候选改善服务或真实成本 ＋ 消融定位到机制。
