## 1. 补两个审稿人一定会要的对照

### 1.1 文献最强门限 eh_aoi 也失稳（排除"ea_aoi 参数太激进"的反驳）

`EhAoiPolicy` 是 Arafa et al.（arXiv:1905.06679）有限电池 EH 最小 AoI 的**联合门限**结构：
dense ⟺ (soc≥θ) **且** (AoI>θ_age)，比 ea_aoi 的独立叠加更接近文献最优。能量轴 48h：

| 能量档 | ea_aoi | **eh_aoi（文献）** | anchor（义务相位） | fixed900 |
|---|---|---|---|---|
| 宽松 | .830 / soc.32 / air1317 | .957 / .85 / 418 | .998 / .93 / 136 | .999 / .93 / 139 |
| 紧张 | .292 / 活1.0 | .899 / 活11.7 / .54 | .997 / 活13.7 | .999 / 活13.7 |
| 极紧 | .230 / 活0.7 | .852 / 活7.2 / .24 | .982 / 活8.2 | .984 / 活8.2 |

eh_aoi 比 ea_aoi 好（联合门限在无中断时不盲密），但**仍显著失稳**：它的 AoI 仍是端到端量，
回传一断照样 stale，于是中断期照样 dense、电量照样耗尽（soc .24、空口 2.4 倍）。**失效不依赖
某条基线的参数选择，而是"用被回传污染的端到端 AoI 门控采样"这一结构本身。**

### 1.2 "门控采样"在本 task 与"只门控上报"逐位相同（修正 doc11 的一处乐观说法）

report_only（采样恒 3600、只按义务相位调上报＝v1.1 已有 ObligationSlackPolicy 思路）与
anchor_full（同时门控采样）在三档能量轴**逐位相同**。原因：v1.1 task 义务 1h 窗＋1h 宽限、
数据率极低，**稀疏 1/h 采样已满足义务，"临近才密采"的分支从不触发**。因此：

- 不能把"用可交付性门控采样"当成在本 task 有实测增益的新机制——它在本 task 是**死分支**；
- 它真正的角色是**安全条件**：当某策略本来就会密采（ea/eh）时，用可交付性拦住无意义密采；
  而开环 fixed 从不密采，天然满足，所以 anchor 在本 task 退化为 fixed（D 时间线两者逐位相同）。

dense600 小时数：ea/eh=47（几乎全程密采），anchor/fixed=0。**因果链闭合**：
soc 够就 dense（不看交付）→ 回传中断期数据发不出却持续 6 倍密采＋300s 快报 → 弱采能补不上、
h16 耗尽判死 → **h20 回传恢复时节点已永久死亡，此后 28h 该站点零数据**；锚定可交付性/开环
稀疏者在中断期省下电、甚至把电池充满，恢复后继续服务。这正是"供电受限＋间歇回传"场景最该
避免的失效，且是**反馈信号选择**造成的、不是链路或电池硬件造成的。

## 3. 第一阶定论（证据已从三个子空间一致收敛，不再在实时闭环里找正收益）

- **发送侧（装包/排序）**：数据率极低、备用容量≥积压，真实 deadline 排序与 EDF 逐位相同（死参数）。
- **上报侧（只调 report）**：偷看中断时刻的上界都赢不了全程 fixed900（.991<.998、信令更贵）。
- **采样侧（调 sample）**：本 task 密采无服务收益，故"按需密采"无舞台；但**错误反馈（端到端
  AoI/纯 SoC 阈值）驱动的密采会在长中断＋弱采能下正反馈耗尽、恢复后永久死亡**，文献门限只缓解。
- **净结论**：在与合作方一致的 v1.1 task，实时采样-上报闭环的**最优解是开环**（固定稀疏采样＋
  适度上报＋自动备用 failover，.999、信令最少、全程稳健）；智能闭环无平均增益，且反馈选错会
  显著有害。这不是失败，而是把"智能落在哪一层"切出来：**实时执行层不需要 agent。**

## 4. 论文骨架（第一阶＝通信执行层，规则获益即贡献，不依赖 LLM）

1. **场景与形式化**：灾前山区、Class A（命令延迟、可能永不生效）、接入/回传分离、主/备间歇、
   供电受限；受控到达 H_i(a_up) 被延迟配置动作内生改变（区别 ICLDC 外生到达、Zakeri 单跳即时反馈）。
2. **执行层设计与正确性**：零复制叠加的主/备 failover（5 锚点，含"关备用与 v1.1 逐位一致"）。
3. **核心发现（反直觉失效模式）**：端到端 AoI/纯 SoC 反馈在分离架构下被回传状态污染，驱动采样
   正反馈失稳；能量轴＋位置消融（ea_gw 部分缓解）＋驱动信号消融（anchor 消除）＋文献门限对照
   （eh_aoi 仍失稳）＋单节点因果时间线（§2）五重证据。
4. **设计原则与适用边界**：反馈锚定网关本地可交付性/义务相位；低数据率稳态开环近最优（上界证明），
   闭环价值是"不犯错误＋对时变的鲁棒保险"，不是平均 SOTA。诚实报告 anchor 在本 task 退化为开环。
5. **第二阶（agent 的真正位置，另立）**：慢时间尺度的通信编排与恢复——中断/退化/恢复时跨实体选
   通信手段、重配置执行层、编排备用/中继/恢复序列；在同一执行层上比"规则 planner vs tool-agent"
   的开销与灵活性。这对应谱系③（ESWA/SCS），第一阶的失效证据正好说明为什么需要上层在恢复后
   重新编排、以及为什么不该让上层去逐拍控制采样。
