# Task v1.2 — 04 · agent gate 预注册（冻结）：开放世界装包里，零样本 LLM 是否存在强规则吃不掉的残差

日期：2026-09-14。前置：`01` 来源审计（唯一现实动作面＝primary 蜂窝＋受限备用短报文）、
`02` minimal probe 预注册、`03` minimal probe 结果（分支②：**同权、公开期限、单资源下 EDF 到顶，
"选哪几条"不构成智能需求**）。本文件在看到任何 agent gate 结果**之前**冻结任务、决策者、判据与解读上限；
**实现与结果不得反向修改本文件的阈值与档位定义**（如确需改，另写 04b 变更说明并保留本件原文）。

## 0. 一句话问题与它在主线里的位置

minimal probe 把 agent 从"同权条目选择"里驱逐了；EDF 到顶依赖四个前提（作业同权且价值已知静态、
装整条不可区分、期限公开确定、环境平稳模型正确）。**本 gate 只在前提前两个被打破的世界里测一件事**：

> 当一条 200 B 短报文机会面前的候选**价值不等、且价值必须从非结构化、组合化、演化的现场语境推断**时，
> 一个零样本 LLM 相对"该设定下最强的**冻结**规则"，是否产生**统计显著且有实际量级**的真实价值捕获增量？

这是 doc 65 统一判据 `useful intelligence = relevant observation × causally-effective action ×
enough time × residual headroom` 中，唯一尚未被三条证据链关闭的格子：**价值/内容从开放语境产生**
（audit §3.4 的 open-world task orchestration gap）。**正负都闭环**：
正＝精确定位 agent 不可替代的最小充分结构；负＝连同开放世界一起给出"agent 不被需要"的可发表充分条件。

## 1. 形式化（冻结）

### 1.1 单次装包决策（instance）

一个备用机会 t，待发池 `P_t` 含 n 条候选（**n 恒 > K，保证存在选择压力**；n∈{6,8,10} 灵敏度）。
每条候选 i 携带（**所有决策者看到完全相同的这些，谁都看不到 v\***）：

* 结构化特征 `x_i`（数值/类别，字段固定）：`vel`（位移速率 mm/d）、`acc`（近窗加速度，趋势）、
  `rain`（当前雨强 mm/h）、`rain_trend`（雨势 −1减/0平/+1增）、`stale`（距上次成功上报 h）、
  `health`（设备健康 0..1）、`slack`（距该条 deadline 的秒）、`hazard_prior`（该点历史隐患等级，
  作为**可见的类别字段**给出，规则与 LLM 都能看到，避免信息不对称）。
* 自然语言语境 `c_i`：把**同一批事实**叙述成一句现场态势（含定性词），信息不超过 `x_i`
  （生成时由 `x_i` 模板化，自检：`c_i` 不得出现 `x_i` 没有的数值）。
* 两种承载形态与字节成本：`full`（s_full=40 B，价值 v_i）、`digest`（s_digest=18 B，价值 ρ·v_i）。
  **单包字节预算 B=200 B**（audit：北斗单包 ≤200 B）。决策＝选一个子集并为每条选 full/digest，
  使 Σ 承载价值最大。→ 这同时覆盖"选哪几条"与"200 B 内装什么内容"。

### 1.2 隐藏真值 v\*（ground-truth value，决策者不可见，仅评分/oracle 用）

**三个真值机制档，生成器与参数全部写死在代码、可复算、可审阅；档位标签对决策者不可见。**

* **档 R（rule-recoverable，规则可解＝负对照锚点）**：`v* = softmax-ish 的固定加性专家分`，
  `score_i = w·z(x_i)`，权重向量 **w_R 在本文件冻结、且原样提供给 rule 决策者**（见 §2）。
  即档 R 的世界"价值就是这套线性专家权重"，强规则**理应逼近 oracle**。
* **档 O（open-world compositional，开放组合＝agent 候选主场）**：在加性基底上叠加
  **条件化交互项**（机制写死、但**交互系数与结构不提供给任何决策者**），刻画地灾机理里需要判断的组合：
  例如 (a) `vel 中等 & acc>0 加速 & rain_trend=−1 雨在减弱 & hazard_prior 高` ⇒ 上调
  （内生加速/临滑前兆，而非雨致扰动）；(b) `vel 高 & rain 高 & rain_trend=+ & hazard 低` ⇒ 下调
  （雨驱扰动、会随雨停消退）；(c) `health 低 & 某特征异常突出` ⇒ 该异常可能是传感器故障、价值打折。
  交互项的**有无/方向固定**，**强度系数逐实例由种子在冻结区间抽样**，使真值不是几条可被轻易逆向的离散 if。
* **档 M（mismatch / 漂移）**：候选分布相对 rule 的"标定世界"发生漂移——冻结一组 rule 未见的共现
  （如 `stale` 很大但其实是链路问题不是现场恶化；`health` 骤降伴随多通道一致异常 ⇒ 是真事件而非故障），
  检验固定规则被漂移特征带偏、而常识判断可纠偏的程度。档 M 规模小于 O（第二轴，做小）。

> **自欺防护（审稿最致命点，先写明）**：档 O/M 的真值是受控生成器造的，因此本 gate 的合法声称**只**是
> "**存在一类可精确定义的装包问题，其上零样本 LLM 超过被冻结的最强线性规则，且超额随语境组合复杂度单调**"
> （存在性＋机制刻画），**不是**"真实地灾现场 LLM 必然更好"；外推到现场需真实数据，列局限。

### 1.3 序列维度

**第一批只做单机会装包**（一个 t 上的选择），干净判别"价值/内容选择"残差。
"价值随演化灾情动态重估"（多机会、排序键本身被更新）留作第二批：仅当第一批 H0 时才上，避免一次铺太大。

## 2. 决策者（arms；相同合法输入：x_i、c_i、s_i、slack、B；都不看 v\*/未来/档位标签）

| arm | 决策方式 | 角色 |
|---|---|---|
| `edf` | 只按 slack 升序装满（minimal probe 到顶的旧规则） | 下界对照：证明价值不等时 EDF 失格 |
| `rule_linear` | **冻结加性专家分**（档 R 用 w_R；档 O/M 用**同一套 w_R、禁止看真值重调**）× **价值密度 0-1 背包**（按 v_hat/s 贪心＋一次 full/digest 取舍） | **主对照，必须做强**："领域知识写成固定规则"的天花板 |
| `rule_text` | 与 rule_linear 同，但额外用**关键词/正则**读 c_i（固定词表，冻结）做有限修正 | 防"LLM 能读文字、规则不能"的廉价载体优势 |
| `llm_flash` | DeepSeek **flash**，零样本、temperature=0、严格 JSON、`thinking:disabled`；事实以结构化 JSON＋c_i 给出，输出每条 keep/drop 与 full/digest。**另跑 1 遍 t=0.3 估变异** | 受检 agent |
| `oracle` | 看到真 v\*，0-1 背包（含 full/digest）精确解/枚举最优 | 天花板，算各 arm 遗憾 |

**第二基线闸门（rule_nonlinear，流程强制）**：若且仅若第一批 `llm_flash` 对 `rule_linear` 初步满足 H1，
**必须**再补一个能看交互项的强基线——用**独立生成的训练样本**（与评测实例不同种子）拟合的浅层模型
（逻辑回归/梯度提升或固定深度专家树，输入同样是 x_i，**不使用评测实例真值**），重测。
**只有 LLM 也显著超过 rule_nonlinear，才允许写"规则吃不掉"；否则结论降级为"残差可被少量标注＋经典 ML
消除，LLM 的优势是零样本/免标注，而非不可替代"。** 这一条把"赢弱规则"的过度声称在流程上焊死。

## 3. 数据生成与规模（冻结）

* 生成器确定性、种子驱动；评测实例种子集合 `SEEDS_EVAL = 0..11`（12 种子），每种子每档 18 个实例
  ⇒ **每档 216 实例、三档共 648 实例**；rule_nonlinear 的训练集用**不相交**种子 `SEEDS_TRAIN=100..111`。
* n∈{6,8,10}：主分析 n=8；n=6/10 为结构灵敏度。ρ∈{0.6,0.7,0.85}：主分析 0.7，余为灵敏度。
* 每个实例五 arm 配对（同一池、同预算）；LLM 每实例 1 次 t=0 调用＋主档 1 次 t=0.3（仅主档估变异）。
* 成本上限（硬闸门）：≤700 次调用、单次输入 ≤1200 tok、输出 ≤220 tok；flash 峰值价估算总额
  **≤¥2（人民币）**，账户与他线共用，超限即停并记录。
* LLM 输出落盘缓存（key＝prompt 哈希＋model＋temperature），**可复跑不重复扣费**；解析失败按预注册
  的固定回退（记 `parse_bad`，该实例 LLM 退化为 rule_linear 选择并单独计数，**不得重试到"答对"为止**）。

## 4. 判据（先写定，看到结果不改）

对每实例算 `value(arm)=Σ 承载 v*`、`capture(arm)=value(arm)/value(oracle)∈[0,1]`、
`regret=value(oracle)−value(arm)`。主统计量＝**同实例配对差** Δcap = capture(llm)−capture(rule_linear)，
跨实例配对 bootstrap（10000 次，rng 固定）**与** Student-t 并列，两者都排除 0 才称显著。

1. **公平性闸门（不通过则整组判 INVALID，不得报任何 agent 优势）**：
   (F1) 档 R 上 rule_linear 的 capture 中位数 **≥0.98**（它本就拿到正确权重，必须接近天花板）；
   (F2) 档 R 上 |mean Δcap(llm−rule_linear)| **<0.02 且 CI 含 0**（LLM 不应在规则可解世界"凭空赢"）；
   (F3) edf 在档 O 的 capture 必须**显著低于** rule_linear（否则说明价值不等没真正构成压力，任务无效）。
2. **H1（agent 有不可替代残差）⟺ 全部成立**：档 O 上 Δcap(llm−rule_linear) 两 CI 排除 0、
   **mean ≥ +0.05（5 个百分点实际意义阈值，先写死，杜绝"显著但 0.3pp"）**、且 capture(llm) 均值 ≥0.90；
   并且**通过 §2 的 rule_nonlinear 第二基线闸门**（对 nonlinear 仍 ≥+0.03 且 CI 排 0）。档 M 同向为佐证。
3. **H0（强规则充分）⟺ 档 O 不满足 H1**：结论为"即便价值不等、需语境组合，冻结强规则＋价值密度背包
   已捕获绝大部分，零样本 LLM 无具实际量级的不可替代残差"，论文以**负结果的充分条件边界**闭环。
4. **结果三向解释预先写死**：H1 且过 nonlinear ⇒ 定位最小充分结构（写清是组合推断/内容取舍/漂移鲁棒中
   哪个）；H1 但输 nonlinear ⇒ "零样本/免标注优势"的弱化结论；H0 ⇒ 关闭该格子、agent 在本动作面彻底无位。

## 5. 解读上限与局限（结果文档必须复述）

* 不得写"首次提出应急通信智能调度/Agent 必要"；真值为受控生成器，只支撑**存在性与机制**主张（§1.2）。
* 候选事实由模板生成、语言简单，**可能低估也可能高估** LLM 的现场语境优势；真实非结构化报告（含噪声、
  多句、缺失）的迁移性未知，列 future work。
* 单机会、成功率取 1、时延当拍、不计资费/能量、字节以固定 B/形态近似（同 03 号文 §9 简化）。
* 单模型（flash）、零样本；跨模型/带示例的泛化不在本批（not in scope），H1 后才考虑换强模型做稳健性。
* `hazard_prior` 等字段对所有 arm 同可见；若现实中某信息只有文本可得，须另设非对称信息实验，不在本批。
