4. **开环与可交付性锚定全相空间不劣**：不存在"闭环更好"的格子，第一阶"实时层开环近最优"在二维参数面成立，
   不是单点结论。

## 3. 失稳的半定量判据（写作用，待解析化）

节点在中断期的净电量变化 ≈ 采能补充 −（密采次数×采样功耗 + 快报次数×上报功耗）。开环/anchor 保持
1/h 稀采，中断期净充电（D 时间线：25→50mWh）；ea/eh 进入 dense600（6 倍密采）+fast300 上报，净放电，
当 **中断时长 × 密采净放电率 > 电池可用缓冲** 时越过死亡线（soc<单次采样能耗即永久判死），且死亡不可逆，
回传恢复后该站永久缺失。eh 的联合门限提高了进入 dense 的 AoI 门槛＝减小净放电率，故前沿外移；只要中断期
端到端 AoI 仍单调增大，门限终将被越过，故不消除。论文可据此给一张"能量缓冲—中断时长"设计临界线。

## 4. 第二阶 go/no-go（书面判决）

- **实时采样-上报执行层：NO-GO for 智能闭环。** 证据：发送侧死参数（C-send）、上报侧上界都赢不了开环、
  采样侧密采无服务收益且错误反馈失稳（相图+规模+时间线+文献门限一致）。这一层的贡献是**失效模式与设计原则**，
  不是新控制器，也不需要 agent。
- **慢时间尺度编排层：当前冻结 task 下不立项做 planner 对比。** 理由严格按 doc07 §5.3/§7：慢决策的输入
  （链路二值历史、义务剩余、配额、电量、积压）全是结构化标量、目标是明确的按时交付最大化，标准联合
  MPC/状态机在**相同合法信息与预算**下即可覆盖，不构成"规则信息上做不到"的自由度；而唯一可能让 agent 增量的
  "哪条义务更重要/灾情演化语境"属于非结构化推断，正是 v2gate 已证伪、doc07 §1.2/§1.3 明令不回的老路。
  因此把 agent 作为**讨论与展望**（需要非结构化任务语境才可能有增量，留待后续），不作为本文方法主张。
- **论文定位锁定**：一篇通信执行层论文——分离主备 + Class A 延迟 + 能量收割现场监测中，端到端 AoI/SoC
  反馈的失效区域、机理与"反馈锚定可交付性、稳态开环"的设计原则；与 EH-AoI 文献（Arafa、Zakeri）就
  "即时无误反馈/发送端本地"假设的失效展开对话。规则获益即贡献，不依赖 LLM，场景不换。
