## 0. 结论先行

1. **固定资源下的吞吐控制空间真正关闭（含跨层联合）。** r34 在中断期 h6–20 升级义务上做对称对表：移除能量墙（cap.50 全程密采）**零增量**（delivered 202→202、collected 1181→1181），放宽回传则 202→1120（+918）。结合 doc41（供能侧含 Class A 生效延迟的滚动可行 MPC 退化 dayfeed、鲁棒扫描无安全工作点）与 r30c（全时段墙分解、双墙耦合仅 2.0%），**含全知联合编排/LLM 在内的控制器，在不改变资源或授权时没有可变现的交付增量**。
2. **中断期升级任务的第一性失败是"任务/命令不可达"，不是能量、也不是选包。** 升级任务表与 300 命令随主回传 h20 才穿过中断到达现场，现场 h6–20 始终按最后生效的蓝级 600 采（collected=1181 即蓝级节奏）；r33 离线 h6 全知 EDF 回传装填宣称可装 420，实测仅 9 兑现——差距来自"假设全量义务窗起点即供样"，而现场根本没收到黄级任务。
3. **可行性证书在两类时机成立且高精度：**
   - **编制时（中心 h6）**：仅凭公开备份节拍（1200 s 槽）与黄级交付窗（300+300 grace=600 s）的几何关系，确定性识别 **602 个窗内无任何回传时刻的义务（S_time），对终局 588 个 S_time 100% 召回、0 假阳，提前 0.2–14 h（中位 7.2 h）**；这是零随机量、可证明的结构证书。
   - **到达时（现场 h20）**：任务表延迟到达当刻，网关凭本地完整 heard/转发日志，对 2136 个已过 deadline 的义务做**段归因，准确率 2136/2136=100%**（r32）。
4. **真实 agent（deepseek-flash）在同体、同合法信息下，仅追加一份可行性证书，行为即从"段误判 + 无效命令风暴 + 谎报在执行"转为"段级正确 + 合法 + 诚实"**（r36，三个真实决策点）。证书的增量不是替 agent 做数值优化，而是把它原本能看到却未整合的命令账本/链路段/容量几何**编译成段级结论**。
5. **真实代价：** 中断期经北斗短报文备份送达的记录中 **45.6%（219/480，1270 B/2782 B）在到达时已过其义务交付窗**（r35）；证书可在发送前抑制这类无效备份（资费），且不减少任何 on-time 交付。

论文贡献因此**不是**"agent 多送数据"，而是：在硬资源墙与连接中断下，让系统对授权监测任务的**承诺与实际执行一致**——编制/到达时给出带段定位的可行性真值，对结构性不可行提前数小时零假阳声明，对不可达/超容量部分在标准授权内合法降级或请求资源，而非静默违约或徒劳致死。

## 1. E1 投影器声明质量（r32、r33）

### 1.1 现场侧：任务表延迟到达的"即到即段归因"（r32）

- 主口径：seed0、48h、14 节点、cap .05、peak .03、主回传中断 h4–20、备份 r1200/78 maxcov、UP_ONLY（h6 升 300）、任务表随主回传 h20 到网关。终局 n=7560，失约 4535（S_cap 1945、S_time 588、S_energy 2002，delivered 3025）。
- 严格按 t 截断构造现场合法视图（taken/heard/received ≤ t；义务在 mission gate 到达时刻 ka 后才可知）。
- **ka ≥ deadline 的义务 2136 个**（黄级任务表 h20 才到，其 deadline 全在 h20 前）。在 t=ka 当刻，用网关本地完整日志（heard/转发/节点报告）+ 公开槽几何重放段归因：**正确 2136/2136 = 100%**（真值段 S_time 588、S_cap 977、S_energy 571）。
- 反证信息边界：现场在 deadline 前能发的**确定性提前证书仅 4 条且段错**（首段疏义务的边界情形）。即**现场侧对中断期黄级义务物理上无法提前预报**（任务表未到），只能到达当刻回溯——这本身是 mission-unreachable 的实证，而非投影器缺陷。
- 初版回溯归因只有 .267，是实现 bug（截断到 ka 的视图 + 未按 on-time 判交付）；改用本地完整日志 + on-time 后 100%。纠错过程留痕。

### 1.2 编制侧：h6 确定性结构不可行证书（r33）

- 中心 h6 编制黄级任务时掌握完整义务表、网络侧中断状态与公开备份参数。用**乐观模型**（doc33 §7.2：乐观假设样本在窗起点即到网关、能量充足，隔离回传墙；连乐观都不可行才发不可能证书）：
  - 备份槽 t %1200==0、净荷 58 B（displacement 6 B/条），按字节 EDF 最早可行槽装填；
  - 窗口 [lo, dl=lo+600] 内无槽 → **S_time 证书**；有槽但全局装填不下 → **S_cap 证书**。
- 中断期升级义务 n=2338（终局失约 2136，delivered 202）：
  - **S_time 证 602：其中 588 与终局 S_time 完全一致（100% 召回）、14 落在 h19–20 主路恢复边缘被判 S_cap、0 假阳。** 提前量 = deadline − h6，0.2–14 h、中位 7.2 h。该判定只用槽-窗几何，**不含任何随机量，多 seed 不变（结构性）**。
  - S_cap 证 1316：552 段正确，**571 实为 S_energy**（乐观能量假设之故），193 假阳（deadline 临近 h20、主路恢复送出）。→ **容量/能量混合段不能用乐观能量模型发确定性证书**，须现场到达后用真实积压（r32）或在线容量分配。
  - 离线 EDF 称 guaranteed 420，终局仅 9 交付（411 落空）→ 见 §2，根因是供样/不可达而非回传装填。
- **机制分层结论**：编制侧（粗粒度、大提前量、只发零假阳的结构/不可达证书）与现场侧（细粒度、到达后真实积压段归因 + 近期容量 EDF）分工；"容量竞争具体谁落选"依赖在线随机状态，不应在 h6 假装可逐义务确定。

## 2. 固定资源联合最优上界收尾（r34，回应 doc38「完整联合 MPC 未做」）

对中断期同一义务集（release≥h6、deadline≤h20）四组对表：

| 工况 | 采样/能量 | 回传 | collected/heard | delivered |
|---|---|---|---|---|
| base dayfeed | cap.05 | r1200/78 | 1181 | **202** |
| O_en（移能量墙） | cap.50 全程 300 | r1200/78 | 1181 | **202（增量 0）** |

- **移除能量墙在中断期零增量**：cap.50 comply 本应全程 300 密采，但 collected 仍 1181——因为黄级命令同样要经主回传→网关→Class A，中断期到不了，现场维持蓝级 600；能量在该段根本不构成约束。这把"夜间能量墙"（doc41，作用于命令可达后的深夜）与"中断期任务不可达"（r34）清楚分开。
- **回传容量是中断期硬墙**：现场采到/听到 1181 条，固定备份容量只送 202，放宽回传送到 1120（+918）；maxcov 已把固定容量用满，选包策略无空间。

- 与 doc41 合起来：供样侧（命令可达后）全知滚动最优退化 dayfeed；回传侧 h6 全知装填的理论余量被供样/不可达吃掉；两个子空间的全知上界分别逼近反应式强基线 dayfeed+maxcov。**固定资源、任务表不可达设定下，中断期可交付 ≈202 是强上界。**

## 3. 真实代价：无效备份资费（r35）

- 中断期备份：75 包、750 记录、5848 B，包基本发满（净荷 58 B ≈ 9–10 条 displacement）。
- 经备份在 h4–20 送达中心的 480 条记录中，**on-time 261、过期 219（45.6%）；过期字节 1270 B / 2782 B**。
- 含义：maxcov 按 deadline 贪心，当某槽没有足够 on-time 候选时用积压样本填满，这些样本对其原始 routine 交付窗已过期（短报文按条/包计费，资费已花，新鲜度义务未兑现）。可行性证书（h6 即知 S_time/容量不足、h20 即知已失约）可在发送前抑制过期样本；因 S_time 义务本就无槽、抑制过期不挤占任何 on-time 交付，**这是不损服务的净资费节省**。
- 口径限制（如实标注）：是否省下整包钱取决于计费单位（按条 vs 按包）与整包是否皆过期，r35 给的是记录级资费浪费上界；样本作为原始时间序列对回溯分析或有次级价值，但不改变其对 routine 新鲜度义务已失约的判定。

## 5. 机制定稿（C1/C2/C3 与放置）

- **C1 义务级可行性投影 + 带段不可行证书**，分两级：
  - *编制侧（中心，任务授权/变更时）*：乐观模型逐义务沿 采样→接入→回传 求可行分配。只发**零假阳结构证书**：S_time（槽-窗几何无回传时刻）、mission-unreachable（任务表/命令在 deadline 前不可达）、以及用乐观能量仍越界的夜间能量墙。容量竞争等依赖在线状态者不在此逐义务下定论。
  - *现场侧（网关，任务表到达与滚动窗口）*：信息最全、现场自治、中断期可本地发证；任务表延迟到达当刻段归因（已证 100%），并对近期备份槽做真实积压 EDF。
- **C2 标准授权内合法重编译/重协商**：§5.3.3 按预警等级远程调采样/上传频率、§8.4.2 经会商升/降/解除（agent 不判滑坡）、§5.3.7 弱覆盖极端天气双模（场景条件强制）。不可兑现部分 = 维持最后合法配置 + 本地自治 + 带段证书 + 恢复后只下发可保证子集 / 请求增配额或会商降级；**不得静默宣称黄级在执行，也不擅自删除义务**。
- **C3 真实代价**：抑制结构性不可交付义务上的夜间无效密采（doc41：comply 类全程密采死 13 台）与过期备份（r35：45.6%），报告能量/死亡/北斗资费；不声称多交付。
- **agent 的位置**：投影器/EDF/能量账是**层内确定性工具**（规则/MPC 同样可调用，规则获益算通信方法贡献，不算失败）；agent runtime 作为证书**消费者与协商者**——把非结构化授权编译为任务、在不确定/跨系统时发起合法降级或资源请求、对操作员维持承诺-执行一致的可解释说明。**不主张 LLM 比持有完整任务模型的求解器更会数值优化。**
