**保留具名实验的数值，暂缓采用 doc 06 的三链论文闭环；不沿合成重要性打分继续 few-shot。下一候选仅保留：在同一参考部署里联合选择上游上报配置与备用发送，先查有无可执行的联合收益。**

## 1. 本轮有进展，但「闭环」判断超出了证据

### 1.1 C3 换了被测对象

`code/v2gate/ds_client.py` 接收一次八条模板观测，输出重要性分；`arms.py` 调用共同背包器。没有 tool-use 过程、跨机会状态更新、配置生效、失联恢复，也没有供电闭环。

其目标是推断「是否正在发生真实斜坡失稳」的相对重要性。原 [Task v1.1 §1](../task-contract-v1.1.md) 明确研究监测服务，不将通信交付解释为告警准确率。允许单列该合成扩展，但不能把它接成原通信 runtime 研究的最后一道排除证明。

`full/digest` 也不是实际编码或内容选择：收益固定为 `v*` 与 `rho*v*`，字节固定为 72/48，未生成或校验接收端可用载荷。它测的是两种大小选项的组合，不是语义压缩效果。

### 1.2 同源不等于同信息，隐藏效用也不等于公共任务

`world_gen.py::_make_text` 将加速度和健康度压成词语；规则读取原始连续 `x`。LLM 收不到精确加速度、健康度，也不获得 R 档的冻结权重。共同背包器只统一优化器，没有统一观测与任务知识。

本轮离线构造一对输入，保持其他字段相同：
- `acc=0.30, health=0.86` 与 `acc=0.95, health=0.99`；
- LLM 看到的文本**完全相同**；
- linear 分数分别 49.9623 / 57.3754；
- H 档真值分数分别 60.8024 / 73.4324。

这是接口可辨识性的反例，**不是对 216 个实例损失量的归因**。它足以撤回「唯一差别是语境推理能力」的严格同信息说法。R 档真值直接等于规则函数，规则得到 1 是构造属性；不给 LLM 效用权重时，不能把它低于 1 解释成不会通信决策。

### 1.3 合成风险标签不足以认领地学机制

`world_gen.py::_memberships/combo_base` 把「雨势增强且位移加速」减分，将「雨减弱后加速」加分；`_stratified` 又按 oracle 选中、linear/tree 漏掉及分差区间验收实例。

受控挑战集可以这样构造，但支持的是**该条件分布上的比较**，不是此类情形在真实站点的频率或风险排序。seen/held 是作者定义的规则覆盖差异，不是独立站点或真实新机理的外部验证。

「雨驱」与「真实失稳」不能简单对立。[Iverson 的 USGS/JGR 论文](https://www.usgs.gov/publications/regulation-landslide-motion-dilatancy-and-pore-pressure-feedback) 分析降雨入渗、孔压与滑动反馈，持续的降雨/孔压增长同样可以导致加速；[USGS 的现场报告](https://pubs.usgs.gov/of/2017/1095/ofr20171095.pdf) 记录了与强降雨相关的滑动加速。因此，目前不能把 LLM 选中高雨强加速项称作「100% 被假临滑欺骗」，应称「100% 选中生成器指定的 distractor」。

这不是断言该生成器标签必错，而是**现有证据不能确定它们是正确的现场效用**。先固定独立评价依据，再讨论模型是否犯错；不能靠 few-shot 学会作者公式来补通信贡献。

### 1.4 预注册闸门没有按其字面通过

[04b §6](04b-pre-registration-change-2026-09-14.md) 规定公平闸门不过则整组 INVALID，F2 要求 R 档绝对差小于 .02 且区间含 0。实际差为 −.041678，区间不含 0。

「因为方向对 LLM 不利，所以仍可判干净 H0」是看到结果后的解释变更。可保留描述性负差，报告 **F2 失败、确证性判决未通过**，不能声称严格遵守冻结的三向判据。36 例温度子集方向相同也只能称未观察到翻转，不能证明温度鲁棒。

## 2. C2 不能支撑的两条强结论

### 2.1 opportunity 与 EDF 的同序是代数结构

`backup_model.py::_opportunity_score` 为当前所有条目使用同一个 `p_up` 和 `streak_bonus`，唯一逐条变化量是期限：

`p_lost = (1-p_up)^ceil((deadline-t)/3600)`，其后用 EDF 解同分。

对合法 `p_up ∈ [0,1]`，该量随期限单调不增。因此排序与 EDF 同序；p=0 或 1 时仍由 EDF 解同分。本轮用 200 组历史与随机待发池核对，排序差异 0。

所以「EDF 与机会感知逐义务相同」**没有测试独立的预测决策**。共同历史信号虽然在分数里，实际上无法改变动作；与早期死参数是同类辨识问题。仍可报告不同 FIFO/latest/EDF 工作点，不得据此说有用预测已被 EDF 排除。

### 2.2 固定到达台账只关闭了一个子问题

`run_minimal_probe.py:43` 固定 `PRIMARY_ARM="local"`，之后所有备用策略共享 `h*`。这是隔离备用效应的合理设计，但它不允许备用状态改变上游上报节奏，也不比较联合配置。

> 在固定的数据供应上装包已足够，不推出「如何供应数据＋何时使用备用」也已足够。

主例 97% 非空机会能一次装完，说明该工作点选择压力小；不能由此推导整个参考部署没有控制余量。「速率/容量受限」只证明有限性，是否形成争用还依赖到达、期限、作用终端和能量。

## 3. 标准数值与资源作用范围须分开

本轮阅读本地原文提取件 `/home/orion/Communications/audit_raw/dzt0450.txt`：
- §7.4.2.3 属于卫星短报文段，给出不小于 1 min；
- §7.4.3.2 属于低轨窄带卫星段，给出不大于 200 B；
- §7.4.3.5 在同一低轨段给出 5 s 以上。

来源审计自己已记下这两种制式，但后续 03–06 又将「200 B＋≥1 min」统称北斗硬工作点。组合成保守研究配置可以，**不能说这组约束就是同一标准制式的直接规定**。官网 PDF 本轮未成功获取，发布版对应关系仍待核；上述判断来自已有提取件，不冒充新增官方版本认证。

此外，来源审计 §3.1.1 明确终端级链路与网关汇聚链路不同：
- 每终端独立额度不能自动合成八节点争抢的一份全局额度；
- 挪到网关使队列到达与竞争都改变，不能保证 chooser 相对排序不变；
- full=72 / digest=48 / rho=.7 的组合不是仅由 200 B 上限推出；
- 单次最大长度不等于整个义务期限内只能发送一次。

不因这几点推翻双模通信的工程存在性；收窄的是**具体 workload、拓扑与稀缺程度的来源归属**。

## 4. 对论文主张的处理

[06](06-paper-closure-blueprint-2026-09-14.md) 不宜直接进入写稿，理由不只是缺图：
1. C1 重新引用了 `STAGE2_FINDINGS.md` 顶部已撤回的「强 belief-MPC 到顶、oracle 归因」；两条具体实现接近不是最优性证明。
2. C2 是固定到达的装包探针；C3 是合成价值推断。它们不是覆盖整个策略空间的穷尽分解。
3. 四因素乘积未定义数值映射或证明，应降为诊断框架；若「headroom」定义为可能取得的增益，再拿它预测有无增益，会循环。
4. 从有限负实验不能推得 few-shot、漂移、多机会等是 agent 的「最小充分条件」；它们最多是未测条件，既未证必要也未证充分。
5. 严格测试、来源台账与负结果都是资产，但数量与过程纪律不自动构成新的研究问题、外部效度或可发表性。

同时纠正主线中持续抬高的门槛：**通信方法论文不要求「传统方法无法表达」或「LLM 不可替代」。** 一种有明确问题结构、在公平预算下提高服务或降低实现代价的可解释算法也可能有贡献。优化器是工具或基线，不因它不用 LLM 就使研究无效；反之，仅把现成优化器接入也不自动成为新方法。

## 5. 唯一优先候选：联动持续上报配置与备用发送

### 5.1 来源于 repo 的未测结构

v1.1 已有持续 `report_period` 配置、Class A 生效机会、能源与到达账本；v1.2 引入有限备用动作。然而现有主实验将两者分开：前者面对不可控回传，后者面对固定 local 到达。

待检验的是：**当备用可用性/容量改变时，原本合理的上报配置是否会错过可用发送机会，或为本来送不出去的数据持续耗电？**

只能使用同一参考部署已经声明的可观察反馈、合法上报周期、真实命令生效和存储机制。保持采样义务及本地事件自治不动；不引入新的滑坡风险打分、外部公告或虚构共享配额。

### 5.2 最小方法形态（尚无收益）

规划器输出服务目标；执行层或通信控制器联合决定：
- 本节点的上报周期是否应调整，以及最早何时可能生效；
- 哪些当前真实持有的记录可使用主/备链路；
- 取得新报告或发送反馈后是否需要重算。

对记录 i 应区分 `H_i(a_up)`（受上游动作影响的就绪时间）、`T_i(a_send)`（可能的下游发送时间）和期限 `d_i`。有用路径需满足 `H_i ≤ T_i ≤ d_i`；规划时只能使用合法历史下的分布/区间，**不能读取未来 H/T 真值**。

候选洞见是**上游动作的收益应按端到端可交付概率评估，发送计划必须计入数据就绪与持续配置的生效延迟**。这不是新定理；是否形成方法增量取决于下面对照。

与旧候选不同：不增加副本以「撞」无容量回传，不把 `h*≤d` 当最终目标，不重做位置收益，不通过禁止全部动作保证安全。若只是复现旧背压，按基线处理。

### 5.3 新颖性压力必须承认

[Zakeri 等](https://arxiv.org/html/2311.06522v2) 已联合研究部分可观测、采样/传输与能源约束，不能把「联合、POMDP、节能」当 novelty。可能值得比较的结构是**远端持续配置及不即时生效、分离的接入和主备交付、相同接收机会承载控制**。该论文使用发送端控制器与即时无误反馈；这只是具体模型差别，不足以宣称全体文献空白。

若一条标准联合 MPC 在相同信息/动作下解决全部差额，可以：
- 将其作为通信基线，不认领新 infra；
- 仅在有实际算力/控制开销约束且低成本实现保住收益时，继续研究近似或执行方法。

不能故意给 MPC 错参数而只让 agent 学习；若测未知模型，两方都应能在线估计，且共享侧信息。

## 6. 下一轮有限交付（预计 4–6 h；本轮未启动）

**A. 一份自洽部署卡。** 选定一个制式、一类终端/汇聚结构、实际报文字段与序列化长度、发送周期、反馈范围。标准值、厂商值、研究假设分列。未确认功耗不由最大发射功率当作实际能耗；无共享汇聚依据就不得用八节点共享单包预算承重。

**B. 先做组合对照，不先造新策略。** 同一部署和业务轨迹比较：
1. local＋自动备用；
2. 冻结网格中最强上报配置＋自动备用；
3. 已有自适应上报规则＋自动备用。
三档保留无中断/接入中断/回传中断，记录服务、缺采、上行/下行、空口、可核的能源或备用调用成本。预算不足以争用时直接报告无选择压力，禁止通过改字节或效用公式造残差。

**C. 只有 B 找到具体可改变的损失，才做一条联合决策参考。** 小实例枚举或非预见联合 MPC，匹配信息和算力预算；同时保留「仅调上游」「仅调备用」两条消融。若参考用未来真值，明确只作诊断，不当可实现基线。如果简单组合已够，不进入机制实现。

**D. 交一条逐义务反事实链与方向判决。** 给出相同中断前状态下，证据→配置命令→实际生效→样本就绪→备用发送→交付的链条。至少检查一次「新鲜度/控制延迟去掉后增益是否消失」。先冻结设计再看未用种子；报配对区间，不把新种子当跨站泛化。

晋级需同时有：来源/部署自洽、合法动作能改变损失、公平传统组合仍有差额、候选改善服务或真实成本、消融定位原因。没有差额则关闭**这项联合候选**。不预承诺论文，也不再将关掉一个小探针称作关闭最后一个 agent 格子。

## 7. agent 如何接回，且不转向 LLM 论文

通信机制若有独立收益，再比较规则 planner / 实际 tool-using planner × 原执行路径 / 候选路径。共同任务、证据、目标授权、动作与预算；测通信交付与执行成本，而非能否猜中作者的隐藏地学公式。

如果两种 planner 都获益，支持通用通信执行层；如果只在特定 agent 的具体调用模式下获益，必须给出该调用模式、有效指令语义和成熟管理基线。若一条普通反馈规则已修好，不再给它换名字认领新颖性。

目前有的是**一个未被这批隔离实验回答的联合控制问题**，没有已经存在的正方法结果。值得继续的理由是这个结构仍未检验，而不是不接受负结果。
