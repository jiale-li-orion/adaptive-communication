## 0. 一句话论点

在「山区地灾监测 ＋ 蜂窝主链路 / 北斗 RDSS 短报文备用」这一**现实受限动作面**上，LLM agent 是否
**不可替代**，不取决于模型多强，而取决于统一判据四要素是否**同时非零**。我们用一个判据 ＋ 三条
**预注册、强基线、真实来源锚定**的受控证据链，把"看似需要智能"的自由度**逐格关闭**，并精确给出
agent 仍可能 matter 的**最小充分前提**——这些前提在当前现实动作面不成立。**这是有正面理论贡献的
负结果**：给出"什么时候不值得上 agent"的可证伪边界，和"未来系统满足什么才值得上"的设计清单。

统一判据（doc 65 §0，逐行算得，非格言）：

```
useful intelligence = relevant observation ① × causally-effective action ②
                     × enough time ③ × residual headroom ④
```
任一项≈0，planner 再聪明也不产生业务收益；②的精确含义＝动作能**改变当前承重环节的状态**，
"信息更细/状态更语义化"都不是充分条件。

## 1. 三条证据链是一个层层收窄的漏斗

| 链 | 被检验的"智能需求"自由度 | 最强传统基线 | 结果 | 哪个要素归零 | 主证据 |
|---|---|---|---|---|---|
| **C1 数值/资源优化** | 隐状态推断、多路径选路、能量配给、副本/节奏/探测 | HMM belief-MPC（真实 GE 参数、情景 MPC）、AoI/EH 门限、EDF、固定周期、普通背压、数据 ACK | 强基线到顶后残差被吃掉；**付费探测被普通 ACK 严格支配**；早期 4.3–8.2pp 的 GO 已自行撤回（闭环信念更新修正） | ④残差余量≈0（模型正确平稳时）；②作用在非承重跳 | `multipath_probe/STAGE2_FINDINGS.md`（含撤回留痕）、`results/final_arms.json`、instance-v1 doc 47–65 |
| **C2 同权义务选择** | 一次短报文机会里"选哪几条**同权**义务" | EDF / 机会感知 / 五 chooser | **EDF 到顶**，五 chooser 逐义务 100% 相同（P-B=0）；稀缺走廊量级 0.6–2.4/672（≤0.36pp）；备用链路是工程冗余（P-A 成立）非智能 | ①观察同权、④余量≈0；EDF 与机会感知等价 | `results/v2probe_minimal.json`、doc 03、`attribute_chooser_gap.py` |
| **C3 开放语境内容选择** | 价值不等 ＋ 需**语境组合推断** ＋ 200B 内"**装什么内容**"（唯一理论剩余格子） | 规则能力阶梯 linear<keyword<tree（共用同一最优背包器）＋ oracle | **零样本 flash 打不过最强冻结规则**：R.958 / S.874（输专家树 .996）/ **H.919 输 keyword .933（Δ−.0139，双 CI 排 0，方向负）**；held 残差**零召回**、对抗迷惑项 **100% 误选**；t=0.3 同向 | 零样本通用知识推不出 held-out 机理 → ①虽非零但**无可用于②的增量** | `results/v2gate_rules.json`、`v2gate_llm.json`、`v2gate_llm_t03.json`、doc 04/04b/05 |

**收敛逻辑**：C1 关闭"算得更精"、C2 关闭"同权里挑哪条"、C3 把最后剩下的"开放语境挑什么内容"
做成对 agent **最有利**的受控形态（价值真不等、真要组合、规则阶梯逐级加强、还放了对抗项）仍然 H0。
三链失败机制不同（数值被 MPC 吃、同权被 EDF 吃、语境被冻结规则吃且 LLM 被迷惑项骗），但都落到
四要素乘积上——**现实动作面凑不齐"非它不可"的合取**。

## 2. 论文贡献（写成三条正面贡献，而非"我没做出来"）

1. **可操作判据 ＋ 逐格关闭方法学**：四要素乘积判据；一套可复用的严谨评估协议——预注册先写判据、
   **规则能力阶梯**（线性→单信号关键词→显式组合树）把"规则天花板"做成阶梯而非稻草人、seen/held
   分离已知与未见机理、**对抗迷惑项**（词面像真、机理为假）、决策者**同构**（都只出价值分、交给同一
   背包器，剥离与智能无关的操作能力）、**剂量反应**（组合复杂度 α 轴）、配对 bootstrap＋t 双检验、
   解析固定回退不重试到对、prompt 哈希缓存可复跑。可迁移到其他 LLM-in-the-loop 的 cyber-physical 控制。
2. **一张 intelligence-value 相图**：残差余量沿四个轴的变化——规则结构化程度（C3 阶梯）、组合复杂度
   α（C3：α=0/.25/.5/.75 时 linear 1.00/.94/.84/.74 规则残差单调扩大，但 LLM 未追回）、信道可预测性
   与能量稀缺度（C1：iid>chirpbox>heavy、随能量收紧）、义务同权度（C2）。
3. **agent 值得上的最小充分前提清单（设计含义）**：把"用 agent"从口号变成**可检验前置条件**——
   见 §6。当前现实动作面四条都不满足，故结论是"现在不值得、且知道为什么、以及怎么造一个值得的场景"。

## 6. 仍开放的格子 ＝ agent 的最小充分前提（future work，也是审稿人必问）

1. **非零样本**：held-out 机理零样本推不出 → 测 few-shot 领域示例 / 在线反馈学习能否把 residual 召回
   从 0 拉起（这已不是零样本，结论改述为"标注/示例成本换残差"，须与 rule_nonlinear 同场比）。
2. **模型错配 / 非平稳**：C1 唯一理论缺口——强基线依赖正确且平稳的转移模型；给 MPC 错误/漂移参数、
   让 agent 用语义上下文适应，是唯一可能反转 C1 的轴（C1 §5 已点名，尚未做）。
3. **多机会动态重估**：本批全是单机会；排序键随演化灾情更新是第二批（仅当单机会 H0 才上——现已 H0，
   具备上的条件）。
4. **真实非结构化脏文本**：用真实地灾监测报文/预警记录做 external validity 试点，量化"干净模板"
   相对真实文本对规则与 LLM 的不同影响。
5. **模型规模边界（可选，须预注册）**：在 H 档加 1–2 个更强模型点，回答"残差是模型能力问题还是
   零样本范式问题"，目标是标定边界随规模的移动，**不是换到赢**。
