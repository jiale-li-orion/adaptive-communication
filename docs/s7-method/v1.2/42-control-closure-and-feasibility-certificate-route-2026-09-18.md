## 0. 结论（先行）

1. **H2（任务变更的未决物理后果）被成熟普通组合覆盖，按 doc33 §7.3 关闭。** 七组降级相位（含落在中断窗、夜间、日出、白天）下，"已采但卡在节点（stuck_node）"的升级义务**恒为 0**；降级点边界结果与不降级对照逐位相同；未到期旧密义务由 piecewise＋MissionViewGate 保留、已采样本由 FIFO 接入补发、卡网关样本由 maxcov 续发、命令版本由 fencing 处理；中断窗内的降级授权物理上只能在主回传恢复（h20）后到达（任务表不走北斗），无合法可改变损失。人为构造"看到降级就重置/停发"的弱系统属于 strawman，不做。

2. **控制/协调空间在固定物理资源下关闭——这次用的是对称的逐义务上界，不是 r22 的单策略放宽。** 两条独立分解一致：
   - **物理墙反事实（r30c，全部 0 死亡）**：现状 .400；放宽回传（dayfeed 已采样本无限送）.627；放宽电池（0.50 Wh 全程密采、回传仍稀缺）.541；双放宽 .797。逐义务集合分解：dayfeed 已采到而仅卡回传容量 **1715**、只需更大电池即可 **1128**、**必须同时增电池与增回传的"双墙耦合"仅 155 条（2.0%）**，且这 155 条仍需**物理增容**而非聪明协调。
   - **乐观可行性段归因（r31，doc33 §7.2 乐观模型）**：失约义务中 S_energy（有回传时刻但夜间无电密采）**26.5%**、S_cap（采到且到网关、备份容量/竞争送不出）**25.7%**、S_time（[窗起点,deadline] 内连一个回传时刻都没有：备份槽 1200 s 稀于义务交付窗约 600 s，中断窗内 23.3%）**7.8%**、S_access（节点→网关接入墙）**0%**。
   - 合起来：在 .05 Wh 电池、r1200/78 B 备份、主路 .62、h4–20 中断这一主工作点，**剩余失约可 100% 归因到可定位的资源容量/机会墙**；强普通基线（dayfeed 鲁棒能量＋maxcov 边际覆盖选包＋piecewise/gate 任务视图＋FIFO 接入＋fencing）已逼近固定资源下的可行域边界。**任何控制器——包括全知联合 MPC 与 LLM agent——都不能在不改变物理资源或授权的前提下多交付有意义比例**（双墙耦合 2% 且其本身仍以增容为前提）。这正面满足 doc38 §2 对 r22"把单策略放宽当物理上界"的批评，也对称地关闭了 doc19/doc33 的"跨层联合数值优化"。

3. **论文路线锁定（不换场景、不追求 agent 多交付）**：*Execution-Grounded Mission Feasibility: Obligation-Level Certificates and Lawful Re-Compilation for Intermittent Geohazard Monitoring*。agent runtime 的贡献不在数值优化（强传统自动化已覆盖，论文如实承认并把它们作为层内工具），而在三件强基线**不提供**的能力：
   - **(C1) 逐义务可行性投影与带段定位的不可行证书**：用现场合法可得证据，沿"合格样本→到网关→截止前回传"滚动投影，在 deadline **之前**判定每条义务可兑现/卡在哪段/需要什么资源或授权改变；强基线只事后反应、对未来失约盲视（A0 606 次命令被拒而无感是直接见证）。
   - **(C2) 合法重协商/重编译**：证书指向 S_time/S_cap 时申请授权内的备份配额/改用主路时段，指向 S_energy 时在 §5.3.3/§8.4.2 授权内降级到可兑现周期或延长窗；把"做不到"编译成"当前授权能保证多少、要保证其余需要什么"，而不是徒劳调参或虚报完成。
   - **(C3) 真实代价下降**：在能量墙段不做无用密采、在回传墙段不发注定过期的备份，省电费与北斗短报文资费（即使不增交付）。
   - 收益按 doc38 §6 严格表述为**声明可靠性（提前量、段定位准确率、假阴/假阳）＋代价下降＋合法降级下的可保证交付**；全中断段若无新增实际交付，只写声明可靠性，不写成监测性能提升。

> 这不是"agent 失败"的负结果论文，也不是"agent 优化通信"的正结果论文，而是"**在硬资源墙主导的间歇监测中，任务执行的诚实性与可协商性**"：先证明固定资源下可行域已被普通优化榨干（一个可独立成立的强发现），再给出 runtime 维持任务的正确工件是**可行性证书与合法重编译**而非更聪明的调度。

schedule＝h6 升 600→300，降级时刻扫 h10/14/18（中断窗内）、h22/26/30/34（恢复后），对照 UP_ONLY 不降级：

| 降级授权 | svc | 死亡 | 降级点边界 stuck_node | 任务表到网关 |
|---|---:|---:|---:|---|
| 不降级 UP_ONLY | .4001 | 0 | — | 72000（h20） |
| h10 / h14 / h18 | .598 / .555 / .518 | 0 | **0** | 72000（中断窗内只能 h20 到） |
| h22 / h26 / h30 / h34 | .482 / .461 / .448 / .472 | 0 | **0** | 79200/104400/108000/122400 |

- 越早降级越省电、svc 越高、0 死亡（降级是减负）；全程卡点分类中**从未出现 stuck_node**（节点→网关 LoRa 接入在回传中断期间仍工作，样本都到网关）。
- 未到期旧密义务：`piecewise_routine_obligations`（exogenous.py:260-262）与 `MissionViewGate.segment_ops`（只替换新段区间的 belief）在选包视图中保留；FIFO 持续补发；maxcov 义务驱动续发。
- 中断窗内降级的授权物理上 h20 才到（任务表只走主回传、不走北斗，doc39 限定），延迟期多采/多耗不可合法避免（不可预知会商、无额外信道）。
- **判定：H2 关闭**，不进入论文主张；过程证据进附录（任务变更语义正确性）。

**纠错记录（防止错误上界污染结论）**：第一版 r30/r30b 用 `comply＋harvest_peak=1.0` 当"放宽能量"，结果 .166、反死 13 台——增大白天充电峰值跨不过黑夜（cap .05 存不住整夜密采的电，约凌晨耗尽）；而 `dayfeed＋peak=1.0` 与 peak=.03 **逐位相同 .4001**，证明 dayfeed 缺采不受白天峰值限制、是夜间容量与策略性疏采。正确松弛是放宽**电池容量**（r30c cap .50）。r30/r30b 保留为纠错轨迹，正式数字以 r30c/r31 为准。

### 2.3 为什么这构成"控制空间关闭"的合法证据（对照 doc38 §2）

- r22 的 .718 是"dayfeed 一条策略＋放宽通信"，既非策略上界也非物理上界；本节给的是**逐义务、按链路段、双维独立松弛＋双松弛**的可行域界标，并显式报告双墙耦合（联合套利的理论上限）＝2% 且以增容为前提。
- 控制器不创造电池容量、备份槽频率/字节、主路可用性；在义务"固定窗口独立观测（半开，一份样本不跨义务替代）＋maxcov 已对到网关候选池做边际最优＋stuck_node＝0"的结构下，上游采样/上报择时既不能增加回传槽，也不能把电挪进黑夜（doc41 的天气不可预知＋永久死亡非对称）。联合数值优化的套利缝在该结构中闭合。
- **边界（不夸大）**：能量结论基于 A 层合成半正弦日照与永久死亡吸收态；`restart_threshold_mult` 复机敏感性未扫（复机会放松死亡非对称，可能移动 S_energy 边界，但不改变 S_cap/S_time）；未复现 EH‑POMDP/Zakeri 与 Bacinoglu 阈值求解器（动作面不同：两档持续 Class A 配置 vs 逐次更新），不称复现或否定其模型；节点规模主表 14（5/9/14 轴历史已做）。

## 3. 论文新主张的机制（C1–C3）

**义务可行性投影器（feasibility projector）**，在线、仅用合法证据（CenterView：reports 的 soc/周期/缓存等级/alive/read_at、report_at、newest_taken_at、in_flight、soc_model；网关本地可见 gateway_copies_by_window；已知 schedule 与器件常量；主路最近可达与备份已用配额），对每条未完成义务在每个决策时刻滚动输出：

- 段状态：`no_qualified_sample`（窗口内无合格样本且节点无法在剩余窗内采到，附能量可行性）／`sample_at_node`（合格样本未到网关，附接入机会）／`at_gateway`（已到网关，附截止前回传容量/槽可行性）／`infeasible_even_optimistic`（乐观模型也无机会，附不可行证书）；
- **不可行证书三元组**（义务 oid＋墙段 S_time/S_cap/S_energy/S_access＋所需的资源/授权改变 Δ：加 N 个备份槽/字节、降级周期 P′、延长窗/截止、主路时段）；
- 三类声明（doc38 §6）严格区分：**已兑现**（独立 scorer 核）／**当前不能保证/尚未兑现**（知识边界/进度）／**声明条件下不可能兑现**（乐观模型可行域排除，附证书；启发式没做完不得用此标签）。

**合法重编译器（re-compiler）**：据证书在标准授权内生成动作（§5.3.3 按预警等级调采样/上传频率、§8.4.2 经会商升降级/解除；Agent 不判滑坡风险），只修复受影响依赖、保留无关数据流；不新增即时信道、不预设资源一定获批（请求被拒则维持并如实声明）。

**LLM 的位置**：不做数值优化（MPC/maxcov/投影器是确定性层内工具）；LLM 仅在非结构化授权解释、会商请求文本、多义降级意图处参与，并以 A0/A0-structured/A1 同体前后对照测其增量（doc38）。

## 4. 与先行工作的区分（成稿前逐篇复核 URL，未跑实现不称复现）

- **ICG‑Restore（AI 7(8):294, 2026，https://www.mdpi.com/2673-2688/7/8/294）**：意图对象＋图检索＋预算/时间约束＋候选计划检查＋局部修复，作用于灾后网络资源**可重配**以恢复拓扑；我们处理现场资源在授权窗内**不可改变**时的义务级可行性真值与**合法降级/配额协商**，对象是长期例行监测义务链而非救援任务图，核心工件是带段定位的不可行证书。"意图→对象→检查器"的骨架不单独承载新颖性（doc33 已示），新颖性在执行接地的段级可行性语义与三类声明。
- **OSS‑GPT（https://www.eurecom.fr/publication/8206/download/comsys-publi-8206.pdf）**：按接口文档编排真实网管 API；不提供间歇能量/机会窗下的义务可行性与不可行证明。
- **SABR/CCSDS 734.3‑B‑1（https://ccsds.org/Pubs/734x3b1.pdf）、Network Calculus（https://leboudec.github.io/netcal/）**：提供过载预订/时延边界的形式化工具，作为投影器回传段检验的对照与方法来源，不是任务级编译。
- **EH‑POMDP（Zakeri, https://arxiv.org/html/2311.06522v2）、Bacinoglu 阈值（https://arxiv.org/html/1905.06679v3）、ICLDC（arXiv:2504.14556）**：单源能量感知采样/发送与有界队列形式化；我们是远端持续配置＋Class A 生效延迟＋分离的接入与主备交付＋义务级证书，动作面与放置不同。
- **SDN 一致更新（https://www.microsoft.com/en-us/research/wp-content/uploads/2017/01/On-Dependencies-Loop-Freedom-and-Blackholes.pdf）**：覆盖版本/依赖一致更新，故 H2 版本竞争不计入贡献。

## 5. 实验设计与关闭条件（预注册，先写判据再跑）

- **E1 投影器声明质量（零 LLM，先做）**：在线投影器随时间对每条义务给段状态/不可行证书；以 r31 段归因为 ground truth，报告(i) 对最终失约义务的**预报提前量**分布（相对 deadline、相对 scorer 事后判定）、(ii) **段定位准确率/混淆矩阵**、(iii) 假阴性率（报可行却失约——最危险，等同虚报"已监测"）与假阳性率。强基线对照：EDF/固定阈值/A0 的隐式判断（它们不主动预报，提前量记为 ≤0）。**关闭**：若合法信息下段定位不显著优于"仅按 SoC/截止的简单阈值"，或提前量不足以赶在任何动作生效前，则 C1 收窄为事后诊断。
- **E2 合法重编译（零 LLM）**：投影驱动授权内动作（降级/配额请求/延窗），对固定 dayfeed＋maxcov 与"先知资源 oracle"三方，比**可保证交付（带证书的承诺兑现率）**与真实代价（耗电、备份包数/字节、资费）；消融去段定位、去提前量。**关闭**：若重编译既不提高可保证交付、也不降低代价，则 C2 关闭。
- **E3 真实 Agent 三层臂（doc38）**：A0＝通用 agent＋完整合法历史＋持久 shadow＋相同确定性求解工具＋明确执行语义；A0-structured＝再加普通结构化状态/未决操作/常规核对；A1＝再加投影器证书反馈。同 agent 加机制前后，3–5 条轨迹含可靠链路负对照；工具只读已收证据、写配置返回排队/送达/生效阶段、规划不得调 evaluate()/读真值。A1 相对 A0-structured 的增量才是 agent 机制贡献；规则/MPC/投影器获益计入通信方法贡献，不视为方法失败。
- **复机敏感性（边界扫）**：`restart_threshold_mult=k` 扫若干档，报告 S_energy/死亡结论的成立范围；能量宽人工况（更大电池/更稳采能）仅作边界说明，不回搬为供电受限场景主张。
- **最终收成**：若 C1–C3 中至少一项在公平对照下成立，按 doc33 §10 工作标题出 LaTeX 初稿（来源支持任务→强基线可行性边界（R20/doc41/r30/r31）→真实 agent 的自然失约（A0）→可行性证书与合法重编译→可保证交付/声明可靠性/代价的端到端证据）；若 E1–E3 全部关闭，按 doc38 §7.5/doc33 §10 诚实评估"强基线可行性边界＋负结果"是否足以独立成文，**不自动推出可投、不回退去改紧任务或换场景**。
