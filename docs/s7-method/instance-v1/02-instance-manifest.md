**扩充线索（待核，暂不写入本表）。** 第二份证据台账（[`source-audit-2`](../task-design/source-audit-2-2026-09-13.md)）
列出了一批可能由**政府协议与采购文件**支持的能力——读取/设置告警阈值、状态上报周期与心跳周期、
版本读取、远程复位、**自记数据块读取**、三种电源模式、远程校时。**若逐条定位核实，本表可从
"需外部输入"降级为"有政府文件支持"，动作空间也随之显著扩充。** 在核实之前不写入，

**三条不许假设的。** 一、字段存在**不证明**现场频繁使用。二、**序列号不自动等于**持久幂等、

因此不能假定"改配置"与"获取数据"必需两次独立下行，**也不能反向假定**该上报是回复后新采的。

**能源这一块的处置（回应"物理层假设须重判适用范围"）。** 旧的机制隔离实验为了让对比不被
"节点全死"淹没，设了**偏冷气候基线**与 **0.5 加热比例**。**这两个值不自动成为新实例参数**：
新实例的采能与温度必须是**外生过程**（v1.1 §8），按站点给；0.5 加热比例是旧实验的**对比设计**，
不是站点事实。最小实例因此先用"恒定采能 + 不冷"把闭环跑通，并在本表标为 A 待定。
