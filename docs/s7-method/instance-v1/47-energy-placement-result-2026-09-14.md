## 三、逐条判读

- **R1（配对基准）——通过。** O0 无中断档下，网关相对中心**几乎没有差**
  （Δ服务 **+0.60 条 = 0.36 个百分点**、Δ缺采 −0.60）。⇒ **两个位置在中断前基本一致**，
  O2 的差**不能**归给"位置本来就有的差别"。
- **R2（主判读）——正结果。** O2 回传中断 9 h 下，网关位置相对中心：
  **缺采 14.8 → 0.1（Δ = −14.70 条 = 8.75 个百分点，10/10 种子更好、0 更差）**，
  **少死 1.0 个节点**（1.1 → 0.1），**末电量最低值 0.00003 → 0.00285 Wh（95 倍）**，
  服务 **+5.70**。**代价**：能耗 **−0.00143 Wh（略降）**、证据年龄中位 20643 → 60 s。
  ⇒ **"更及时的现场能源证据"确实阻止了原持续耗电反例中的不可恢复缺采。**
- **R3（O1 的角色）——通过，且是本轮最关键的归因证据。**
  **接入中断档下没有这个收益**：Δ服务 −0.50、**Δ缺采 +1.00（0 更好 / 3 更差）**、末电量 −0.00001。
  ⇒ 收益**来自回传断续**，**不是**单纯来自"位置更近"。
  **这一条与判别 A 的情形正好相反**：判别 A 里接入中断**无法**消除"少一跳"的优势；
  这里接入中断**消除了**优势——因为收益依赖的是**中心看不见却还在按旧读数下命令**这件事，
  而接入中断对两个位置**一视同仁**地切断了新证据。

### 机制（可逐步对账）

回传断 [3 h, 12 h) ⇒ 中心**既看不到也发不出**，但它**保留着 h3 的旧读数**并继续重申 dense
（证据年龄中位 **20643 s**）⇒ 节点被耗死（末电量 **0.00003 Wh**、死 **1.1** 个）⇒ **缺采 14.8**。
网关照常听到节点（证据年龄中位 **60 s**），**中断开始后降档 10 次** ⇒ 末电量 **0.00285 Wh**、
死 **0.1** 个 ⇒ **缺采 0.1**。**这正是 §31 与 Human 复盘都指出的"陈旧但可信的证据主动把节点推向 dense"。**

## 四、R4：这条收益**属于谁**（必须写死）

**它首先属于「现场能源控制与执行位置」。** 具体地：

- 收益来自**把一条既有的能源反馈规则（`ea_nb`）放到网关**，即**普通网关规则**；
  按 doc 43 §八.4 末句「**若普通网关规则保护了采集，只记架构收益**」⇒ **只记架构收益**。
- **预装同一能源规则的网关就是这条基线本身**——它不是"本文机制击败了谁"，
  而是"**同一条规则换个位置**"。
- **不得**把收益算给条件计划、算给 agent、算给任何"本文独有机制"。
  doc 39 差额表的**第三列（本文额外机制收益）仍然为空**。

**但它同时更正了 doc 39 第一列的一个说法**：**架构收益不是恒为 0**。
在**供电宽松**条件下它确实是 0（判别 A：`aoi` 臂含中断三档 Δ = 0.00）；
在**能源受限 + 回传断续**条件下它是**正的**（本轮：Δ缺采 −14.70）。
⇒ 正确的表述是「**架构收益取决于条件**」，而不是「架构收益为 0」。

## 五、限定

- **10 种子**，单实例族、单一基底 config、**单一策略**（`ea_nb`）+ 零控制参照（`local`）；
  **前缀检查显示 4/10 种子在中断前两位置已不同** ⇒ 直接差含与中断无关的成分，**交互差**才是更干净的对比。
  换策略（如 `aoi` 或带滞环的 `ea_*`）**未测**。
- **`local` 的位置差恒为 0 是内建自检，不是结果**——它只说明 `placement` 是唯一被改的变量。
- 缺采的**逐义务台账**在**当时**并没有落盘（本文原句不实，已由 doc 49 补上）；
  按释放小时的分布仍未展开。
- 本对照**没有**增加任务或硬件能力，**没有**改监测义务；O2 是**新的因子组合**，
  **不是任何已登记结果的重放**——因此它**不是**"已有结果的复现"。
- 结论**只对已测的这一个能源受限上下文**成立；**不得**外推为
  "位置下沉在所有能源受限条件下都有收益"。
