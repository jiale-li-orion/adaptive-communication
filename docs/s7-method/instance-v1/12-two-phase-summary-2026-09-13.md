## 0. 一句话

**两个阶段都没有产出方法主张。** 第一阶段把**实例封版**（task / capability / 证据边界）；
第二阶段用三条并行轨检验**这个实例能支撑多宽的结论**。汇合后的收盘判断是：

> **主贡献落在"有来源依据的 benchmark + failure analysis"这一层。**
> 不是通信/控制方法，也不是 agent infra——理由见 §4。

## 2. 第一阶段：instance closure

### 做了什么

| 项 | 状态 | 落点 |
|---|---|---|
| 连续数据／来源场景 | **部分闭** | 辐照+气温已是 **E 层来源派生**（NASA POWER 2023 逐小时）；**业务来源仍只有 1 个事件簇** |
| A 参数与 manifest | **已闭 13 / 部分 2 / unavailable 1** | `02-instance-manifest.md` §八（16 项逐条） |
| 能力矩阵 | **已闭** | manifest §九（三个 unavailable 项已排除出动作空间） |
| 无方法参与的评分核对 | **4 项全通过** | manifest §十 |

### 结论

- **真上界换过两次分母**，最终是 `dynamic_oracle`（逐节点逐小时离线 DP）：168.0 / 168.0 / 146.2（cap 0.05 / 0.008 / 0.004）。
- **最强传统基线是 `aoi`，不是 `ea_nb`**（把 `ea_nb` 当门槛是**把门槛设低了**）。宽松 92.7% vs 91.9%。
- **residual 是分层的**：宽松条件下**采集侧缺口 = 0**（调度层面没有可争的余地），绑定条件下交付侧仍占一半以上，而**交付侧主要是链路属性**。
- **能量尺度不变性成立**：整套能量系统 ×λ（64 倍范围）读数**逐位相同** ⇒ 绝对 Wh **不是现实部署数值**，必须改用无量纲横轴 `A₀ = soc₀·C / load_h`，判据是 **初始自主小时数 ≥ 最长无采能时段**。
- **低温闸门决定 cliff 的严重程度**：`charge_min_c` 是**二值开关**（0/5/10 三个阈值逐位相同），`off` 下 `dense600` 85.4%、开闸门后 **21.1%（−64 点）**——由一个**没有来源支撑的 A 层器件参数**决定。
- **多年份（2022/2023/2024）**：闸门效应三年逐位相同，不是 2023 单年偶然。

### 留下的门槛

**一个公开事件片段乘很多 seed 仍只算一个业务来源场景**；辐照是天气来源、不是业务来源。
所以第一阶段**不认领跨站泛化**——这正是第二阶段轨 A 要处理的。

## 3. 第二阶段：三条并行轨

### 轨 A · Task / benchmark（决定结论能有多宽）

| 做了什么 | 结论 |
|---|---|
| **第二个业务来源场景**（USGS Cleveland Corral，CC0-1.0，常态 900 s、无事件加密） | **核心结构复现**：突发链路上额外中心控制不产生业务收益。取证见 `10-second-source-candidates.md` |
| **链路 trace**：上海 ChirpBox + 南极 LoRa-on-Ice 两个有出处来源 + 突发度参数族 | 偏远部署平均坏突发 **58 h、突发度 27.5×**，比城市突发 **6.3 倍** |
| **A 层敏感性** | 尺度不变性成立；闸门是二值开关；`charge_min_c` **不得写成现场事实** |
| **天气扩到多年份** | 三年逐位相同 |

### 轨 B · Classical control（决定传统方法还能吃掉多少）

| 做了什么 | 结论 |
|---|---|
| **完整 Pareto frontier**（10–11 点，四目标、**不做加权**） | 宽松下 9/11 非支配，**`aoi` 自己被支配**；服务在 92.5% 饱和而代价差上行 2.0 倍、下行 6.6 倍 |
| **文献做法**（EH/AoI、freshness-aware、queue scheduling） | `eh_aoi` 是前沿上的点但**没有抬高高限**；queue scheduling 见下 |
| **delivery gap 拆 controllable / irreducible** | 见 §5 的更正 |
| **缓存服务次序**（`fifo`/`lifo`/`latest_only`，**实例属性不是策略动作**） | **激活条件：连续断链 > 32 × 上报周期**；12 h 任务下**零**，48 h + 40 h 接入中断下把服务 19.5/21.2/20.1/19.7% 提到 **22.7/23.3/23.1/22.9%**、AoI 减半以上 |

### 轨 C · Agent / runtime（决定是否回到 agent infra）

| 做了什么 | 结论 |
|---|---|
| **意图准入账本**（change / same-value / unknown / stale，三处恒等式闭合） | 服务几乎相同而意图生成率差 **11 倍** |
| **生成原因账本**（`unknown_state` / `target_change` / `resend`，三类互斥完备） | 名义下 `aoi` 的 266.4 条意图里 **179.1 条是重发（67%）**，服务相同的 `aoi_const300` 只有 23.7 条 |
| 南极突发下 | `aoi` **99% 的意图是"未知态"、98% 连信道都没拿到**；`ea_nb` 用 **1/50 的意图量、0 条被拒**拿到同样的 38.5% |
| **执行语义** | 保留为 **conditional mechanism**，不再承重 |

## 4. 收盘判断：为什么落在第一层

**不是第二层（通信/控制方法）**：接上**有出处依据**的链路结构后，10 条前沿臂中**跟得上义务节奏**的 8 条，
服务水平极差在 **12 / 18 / 24 / 36 / 48 / 60 / 96 h** 上分别是
**0.00 / 0.02 / 0.04 / 0.05 / 0.14 / 0.16 / 0.29 点**（20 种子）；
而同一批臂在 i.i.d. 链路上稳定有 **3.5–4.5 点**。
⇒ **"中心策略对服务水平几乎无影响"由链路时间结构决定，8 倍任务时长上稳定成立。**

**不是第三层（agent infra）**：生成原因账本已经指出浪费在哪（重发 / 未知态），
**但全部来自 scripted policies**。按既定因果纪律，只有在**真实 LLM planner 自己**产生
重复/冲突/无证据动作、且 host 侧准入层在不改动作面的前提下减少成本时，才能主张。
**门仍然关着**——而本轮给出了接进来之后**该观察什么**的可测基准（那两个计数）。

**两条可独立引用的论文级 finding**（都在 `08-benchmark-pitfalls.md` 与 §6.22）：
**相位锁定抽样**、**标量摘要替代轨迹**，以及本轮新增的 **中心 AoI 实现缺陷**。
共同点：**先证明坐标轴会动，再拿它下结论。**

## 5. 被推翻或更正的旧结论（这条最重要）

| 旧结论 | 现在怎么写 | 原因 |
|---|---|---|
| "转发损与链路损是常数，再聪明的发送调度最多拿回 1–2 条" | **那一列量不到队列顺序的代价** | `delivery_oracle` 固定发送时刻分支用**实测 `heard_at`**，而它就是服务次序的产物。实测 `fifo`/`lifo` 的转发损**都正好是 0**，而交付差 **18 条** |
| "有出处链路下前沿塌缩到 3 条臂" | 只能写**"额外控制没有业务收益"** | 12 h 南极下 10 条臂交付**逐位相同（64.600）**，是**并列**造成 `local` 严格支配；48 h → 7 个、96 h → 8 个非支配点 |
| "所有策略无用结论建立在 12 h 任务上，换时长可能翻转" | **任务时长不是边界**（≤0.3 点，见 §4） | 真正的边界是**上报周期必须跟得上义务节奏**——Cleveland 场景里 3600 s 报一次的臂低 8–18 点，其余 8 条极差只有 **0.06 / 0.25 点** |
| 中心 AoI 这一列 | **已修** | 旧实现按**采集时刻**推进：49 h 运行下"无中断"与"0–40 h 接入中断"给出**逐位相同的 1794.58 s**。修后 4256 → **6763 s** |
| `aoi` 是否占优 / 基线是不是一条 frontier | 传统基线**是 Pareto frontier**：`aoi` 最高服务点、`ea_nb` 低成本点、`local` 零控制端点 | 三者互不支配 |
| "交付侧是链路属性、不是中心决策对象" | **不成立** | `local → aoi` 证明改 report scheduling 就能减少缺送 |

**另外两处必须连着引用的更正**：
- 遥测有用性：**当前 `ea_nb` 的 safe-fallback 语义下**，无偏噪声/观测年龄/大比例缺失损失较小；
  **系统性乐观偏置更危险**——缺失会退回 `local`，而错误的高估会主动选择危险配置。
- 母线电压：单条命令接收能耗 `3.6 V × 11 mA × 2.0 s / 3600 = 2.2e-5 Wh`（一次采样的 4.7%），
  此前按 3.3 V 算成 2.0167e-5，**低了 9%**。

## 7. 能支持 / 不能支持

**能支持**

- 在**这两个业务来源**与**这些有出处的链路时间结构**下，"额外中心控制不带来业务收益"成立，且**不随任务时长（12→96 h）翻转**。
- 能量轴是**无量纲**的；判据是"初始自主小时数 ≥ 最长无采能时段"。
- 意图浪费可以被**精确定位到"重发"与"未知态"两类**，且这两类在生成侧就能消掉。

**不能支持**

- **跨场景泛化**：两个来源**结构同构**（常态周期 + 阈值加密）。
- **"前沿只剩某三条臂"**：那是并列的派生物。
- **把绝对 Wh 当现实部署数值**；**把 `charge_min_c=5 °C` 当现场事实**。
- **agent infra 主张**：证据全部来自 scripted policies。
- **低 AoI = 高按期率**：AoI 只关心最新那一条（实测一档下 AoI 只有 6763 s 而交付率仅 23%）。
