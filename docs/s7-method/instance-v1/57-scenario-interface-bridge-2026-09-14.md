## 写作与实验处置

1. 主文的场景问题仍是单回传、间歇连接和能量受限下的灾前持续监测。
2. 多 WAN 可用作条件扩展，但只有在目标站备用通信、配额、ACK 延迟与控制接口得到确认后才能承重。
3. 当前卫星/UAV 数字、1 h 决策粒度、2 h/12 h 截止和 1950 预算作为 A 层机制探针参数，不与中通服需求直接绑定。
4. `doc 56` 中这一条同价主动探测启发式在报告的服务/成本均值上劣于数据 ACK。它没有证明所有探测策略或全部信息使用方法都无空间；后续对照边界与有限规划见 [doc 58](58-next-stage-plan-2026-09-14.md)。引入不同代价/时效/观测对象的现场探测仍需接口依据。
