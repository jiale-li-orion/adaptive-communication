## 1. 判别的目标与关闭条件

C5 修正后的实测是：紧能量格上"能量族"候选（`energy_lease`/`soc_mpc`/`soc_mpc_cons`/`lease_safety`）
在应用边沿就回退，黄级交付只剩 **559/2016**（A）、**1194/3528**（B，3 seeds），而**不看能量**的固定
TTL8 拿到 **849/2016**、**2020/3528** 且 0 死亡。这个反差的正确读法是"候选失败，且保护可能有代价"，
**不是**"保护必然牺牲这么多服务"。要判断后者，必须补一条同信息、非预知的序列优化参照。

**判定规则（运行前固定）**：

| 结果 | 判定 |
|---|---|
| 普通组合已追平非预知参照（差额 ≈ 0） | **关闭该方向**：不实现新 runtime；候选族的损失归因于它自己的预测口径，不是保护代价 |
| 差额 > 0 且全部可由"简单改阈值"拿走 | 同上关闭：把阈值型规则并入强基线 |
| 差额 > 0 且非预知参照仍显著低于全知参照 | 差额是**信息**差额，不是可实现差额：该方向需要新的观测通道，不是新的终止规则 |
| 差额 > 0 且接近全知参照，且不靠放宽生存要求 | 才进入"压缩状态/分层求解"的技术草图和最近邻方法对照 |

**不许用的论证**：以现有单臂干预代替参照；以"逐个未来分别取最优再平均"冒充在线策略；以放宽死亡
要求或删掉义务换来的服务提升；以预测口径与环境计费的不一致认领业务增益。

## 2. 声明的模型

单节点切片，49 h 地平线，逐拍（60 s）推进。

| 项 | 值 | 层 | 来源 |
|---|---|---|---|
| 电池容量 | **50 mWh** | E | 冻结实例 `capacity_wh = 0.05` |
| 单次采样能耗 | **0.47 mWh** | E | `admission.py sample_wh`；由 342 次采样合计 0.16074 Wh 逐位验证 |
| 单次上报射频 | **0.03099046 mWh** | E | 实测 0.0105677455 Wh / 341 次；声明到 7 位有效数字 |
| 小时负载（稀疏 600 s） | **3.005943 mWh/h** | M | = 6 ×（采样 + 射频），两个分量实测 |
| 小时负载（密集 300 s） | **6.011886 mWh/h** | M | = 12 ×（采样 + 射频） |
| 采能曲线 | `peak · f · sin(π·rel/12) / 60` 每拍 | E | 与 `exogenous.solar_harvest` 同式，`rel` 自本地 06:00 起算 |
| 小时云遮因子 | 均值 **0.7375**、标准差 **0.047** | E | 实测每小时"意向采能／晴空采能" |
| 不确定性离散化 | 等权三点矩匹配 `{μ−s, μ, μ+s}` | A | `s` 是扫描旋钮（`severity`），不是拟合值 |
| 死亡判定 | 任一拍 `soc < sample_wh` | E | `network.py:_take`（`_step_power` 的 `soc ≤ 0` 是它的子集） |
| 应用边沿 | 相位 A：2 h；相位 B：1 h | E | `mission_schedule` |
| 黄级窗口 | A：`[2h,6h)`；B：`[1h,8h)` | E | 同上，300 s 网格 |
| 每节点每小时义务 | **12 条** | E | 3600/300 |
| 节点数 | **14** | E | 冻结实例（网关 1 + 位移站 13） |
| 共同过去 | 0..应用边沿按名义因子推进 | A | 所有未来共享同一过去；起始电量取满值（实测 `initial_soc=1.0`） |

**目标量**：黄级义务**被采集**的条数，= 12 × 密集小时数。**不得删除义务**：目标里没有"放弃哪些
义务"的自由度，只有"密集档覆盖到哪一刻"。

## 3. 信息集与动作能力（三条纪律）

1. **信息集**：策略是 `(相对小时, 量化剩余电量)` 的函数。量化步长 `1e-5 Wh`，状态**向下取整**
   （对安全与服务都不乐观）。策略**不得**使用未来采能、授权终点、中心在线状态、其他节点的状态。
   剩余电量是节点自己量到的量，属合法信息。
2. **动作集**：窗口内每小时 `继续密集` 或 `终止`；**终止是吸收态**——回传中断期间不再有新的授权
   到达，因此不得重入。这条同时定义了能力上界：不引入"单次采样控制"等当前不存在的能力。
3. **风险口径**：在**声明的全部未来**里都不得死亡（严格口径，不设概率预算）。`severity = 0`
   退化为"只在预期采能下可行"，作为对照，不是主口径。

## 4. 三方表与恒等式

| 行 | 定义 | 求解保证 |
|---|---|---|
| 普通组合 | 声明有限族内**最强的可行成员**：固定租约 `ttl k`（**不按窗口长度截断**，租约长于窗口正是现行 TTL8 的形态）、`ttl k` + 电量下限、以及滚动预期门（`max_feasible_dense_until` 的抽象） | 一族逐条求值取最优；启发式 |
| 非预知参照 | 上述动作族内、信息集约束下的**精确最优**（网格上的期望值反向递推 + 全未来安全求交） | 精确（在声明动作族与量化网格内） |
| 全知参照 | 逐未来取"仍能存活的最大密集小时数"，再对路径平均（4000 条，seed 固定） | **蒙特卡洛估计，是参照不是上界** |

```
service(全知) − service(普通) = 信息差额 + 可实现策略差额
信息差额     = service(全知) − service(非预知)
可实现策略差额 = service(非预知) − service(普通)
```

网格 DP 与规则求值是两条独立代码路径：DP 给出规则，规则再交给前推求值，两者必须逐位一致
（`selfcheck_service_agrees`）。核例另用**穷举可达决策格上的每一条规则**独立核对 DP。

## 5. 可手算核例（声明实例）

核例**不复现实测数值**，作用是证明仪器有分辨力：在存在可实现差额的实例上，DP 必须能把它找出来。

| 项 | 值 |
|---|---|
| 窗口 | 2 个小时（h2、h3） |
| 地平线 | 4 h |
| 应用边沿电量 | 2.5 mWh（声明） |
| 终末保留量 | 2.1 mWh（声明；下游固定职责） |
| 量化 | 1e-4 Wh |
| 规模 | 可达决策格 7 个 → 穷举 128 条规则 |

**期望结果**：DP 服务 **20.0**（= 12 + 12×2/3），穷举最优同为 **20.0**；128 条规则中 96 条安全；
**最强的安全固定租约只有 12.0**。即 Δ可实现 = **+8 条/节点**。核例若给不出这个差额，说明仪器
在真问题上的"零差额"结论没有分辨力，不能采信。

## 6. 截断边界（与结论同时引用）

1. **服务 = 被采集，不是被投递**。实测中密集覆盖整个窗口时采集也只有 535/672、投递 283/672；
   应用边沿延迟与备份打包上限不在本模型内。**不得**用投递数的差额解释本模型的结论。
2. **云遮按小时取一个因子**。环境的云是逐拍独立抽取的，本模型抹掉逐拍抖动，只留小时级不确定，
   并用等权三点矩匹配。`severity` 是旋钮，临界值必须与实测标准差 0.047 一起读。
3. **单节点切片**。不含多节点竞争、网关打包、回传可达性。本文件的结论不能替代完整网络结论。
4. **动作能力限于一次租约**。不含重入、不含单次采样控制、不含新的观测通道。
5. **负载常数来自一次实测运行**（相位 A、ttl8、seed 0、节点 n00）。逐小时实测与所声明的
   结构式偏差在 ±0.6% 内；台账校准见第 7 节。

## 7. 校准与可核对性

**常数同源**：`c5_seqref.py` 的声明常数与校准参考的 `declared_constants` 用同一组字面量、同一
表达式算出，因此逐位比对（实测全精度值在同一文件的 `measured_constants`，偏差 ≤ 1e-9 Wh/h，
当前 2.6e-11 / 5.1e-11）。

**台账校准**：把实测记录的逐小时云遮因子喂给本模型的逐拍递推，比较 49 个小时末电量。
冻结参考 `results/reference/c5_seqref_calibration.json` 记录实测轨迹与实测负载，
`audit_seqref.py` 复算并断言 `max|Δsoc| ≤ 5e-4 Wh`（实测最大 **1.13e-4 Wh**，容量的 0.23%）。

**结果登记**：`results/c5_seqref.json` 必须出现在 `results/README.md` 的结果登记表中，
否则视为未登记结果（见 `results/README.md` 的规定）。

## 8. 复现

```bash
python3 code/v3joint/c5_seqref.py --core        # 核例：打印全部算术
python3 code/v3joint/c5_seqref.py               # 写入 results/c5_seqref.json
python3 code/experiments/measure_seqref_calibration.py   # 重测并刷新校准参考

```

`audit_seqref.py` 的判定项：登记、常数与参考一致、核例 DP == 穷举且 Δ可实现 > 0、受检格三方表与
恒等式、非预知性、台账校准。任何一项不成立即红。
