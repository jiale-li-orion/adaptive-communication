# 非预知序列参照（预注册 v2）

**地位**：本文规定"同信息、非预知的序列优化参照"这一判别问题的**模型、动作能力、执行语义、风险口径
与判定规则**。`code/v3joint/c5_seqref.py` 按本文实现，`results/c5_seqref.json` 是它的一次运行结果，
`code/experiments/audit_seqref.py` 按本文判定。引用该结果的任何地方都引用本文。

**v2 取代 [v1](prereg-nonprescient-sequence-v1.md)**。v1 有两处契约错误，独立审阅给出了可直接运行的
反例，
按 v1 得出的"三方零差额、方向关闭"结论**不成立**，归档见
[`results/_withdrawn/2026-09-20-c9-v1-semantics.md`](../results/_withdrawn/2026-09-20-c9-v1-semantics.md)。
v1 原文与 v1 结果（`results/c5_seqref_v1_semantics.json`）都保留，不覆盖。

**层标**：**E** 来源事实／**A** 研究选择／**M** 本项目实现。

## 1. 判别的目标、两个差额与判定规则

C5 修正后的实测是：紧能量格上"能量族"候选（`energy_lease`/`soc_mpc`/`soc_mpc_cons`/`lease_safety`）
在应用边沿就回退，黄级交付只剩 **559/2016**（A）、**1194/3528**（B，3 seeds），而**不看能量**的固定
TTL8 拿到 **849/2016**、**2020/3528** 且 0 死亡。这个反差的正确读法是"候选失败，且保护可能有代价"，
**不是**"保护必然牺牲这么多服务"。

**两个差额分别定义、分别判定：**

```
可实现策略差额 = service(非预知) − service(普通)
信息差额       = service(全知) − service(非预知)
恒等式         = 两者之和 = service(全知) − service(普通)
```

**v1 的判定表把二者混为一谈**（写成"差额>0 且非预知参照仍显著低于全知参照 ⇒ 只是信息差额，不能
实现增量"），这是错的：普通 60、非预知 80、全知 100 时两个差额各为 20，可实现的那 20 依然真实存在，
不因仍低于全知而被取消。v2 的判定表如下：

| 判定项 | 结论 |
|---|---|
| 最稀疏职责在声明集合下已破线 | **该风险口径下不存在可行策略**；报告不可行，**不进入**服务差额搜索（§9） |
| 可行，且可实现差额 ≈ 0 | 普通组合已追平非预知参照 ⇒ 这一格无需新机制；把现有强基线记下来 |
| 可行，且可实现差额 > 0 | **这是一个结果**，不论信息差额是否也为正：说明存在同信息、非预知的可实现增量 |
| 可行，且信息差额 ≈ 0 | 该格没有信息瓶颈：进一步观测通道不是增量来源 |

**不许用的论证**：以现有单臂干预代替参照；以"逐个未来分别取最优再平均"冒充在线策略；以放宽死亡
要求或删掉义务换来的服务提升；以预测口径与环境计费的不一致认领业务增益；**把隐藏的授权终点用于
停配置**（§3）。

## 2. 声明的模型

单节点切片，49 h 地平线，逐拍（60 s）推进。

| 项 | 值 | 层 | 来源 |
|---|---|---|---|
| 电池容量 | **50 mWh** | E | 冻结实例 `capacity_wh = 0.05` |
| 单次采样能耗 | **0.47 mWh** | E | `admission.py sample_wh`；由 342 次采样合计 0.16074 Wh 逐位验证 |
| 单次上报射频 | **0.03099046 mWh** | E | 实测 0.0105677455 Wh / 341 次 |
| 小时负载（稀疏 600 s） | **3.005943 mWh/h** | M | = 6 ×（采样 + 射频） |
| 小时负载（密集 300 s） | **6.011886 mWh/h** | M | = 12 ×（采样 + 射频） |
| 采能曲线 | `peak · f · sin(π·rel/12) / 60` 每拍 | E | 与 `exogenous.solar_harvest` 同式，`rel` 自本地 06:00 起算 |
| 小时云遮因子均值 | **0.7375** | E | 实测 0.73877（280 个节点×小时样本） |
| 小时云遮因子**标准差 σ** | **0.047** | E | 实测 **0.0452**、理论 **0.0462**；声明取偏保守值 |
| 不确定性离散化 | 等权三点 `{μ−δ, μ, μ+δ}`，**δ = σ·√(3/2)** | M | 等权三点的实际标准差是 `δ·√(2/3)`，取 δ 使实际 σ 等于声明值 |
| 死亡判定 | 任一拍 `soc < sample_wh` | E | `network.py:_take`（`_step_power` 的 `soc ≤ 0` 是它的子集） |
| 应用边沿 | 相位 A：2 h；相位 B：1 h | E | `mission_schedule` |
| 黄级窗口 | A：`[2h,6h)`；B：`[1h,8h)` | E | 同上，300 s 网格 |
| 每节点每小时义务 | **12 条** | E | 3600/300 |
| 节点数 | **14** | E | 冻结实例（网关 1 + 位移站 13） |
| 共同过去 | 0..应用边沿按名义因子推进 | A | 所有未来共享同一过去；起始电量取满值（实测 `initial_soc=1.0`） |

**v1 的离散化错误**：v1 把 δ 当标准差，于是 `σ` 参数为 .047 时真实标准差只有 `.047·√(2/3) = .03838`，
不确定性集合被缩小到三分之二，且 `s_full = .0510` 被拿去与 `.047` 比较——两者根本不是同一个量。
v2 以标准差为参数，`audit_seqref.py` 断言 `std(levels(σ)) == σ`。

## 3. 信息集、动作能力与**执行语义**（三条纪律 + 一条硬约束）

1. **信息集**：策略是 `(相对小时, 量化剩余电量)` 的函数。不得使用未来采能、**授权终点**、中心在线
   状态、其他节点的状态。黄级窗口终点**只用于计分**，不进入执行（见第 3 条硬约束）。
2. **动作集**：自应用边沿到地平线的每一小时，`继续密集` 或 `终止`；终止是吸收态——回传中断期间
   不再有新的授权到达，因此不得重入。不引入"单次采样控制"等当前不存在的能力。
3. **执行语义（v1 的错就在这里）**：**隐藏终点不得改变执行**。
   * 策略的动作定义在整个地平线 `[应用边沿, 49h)` 上；求值器与 DP **不接受任何"终点"参数**，
     也**不得**在执行到某处后自动接上稀疏。规则只在它自己判停、预告有效期结束、或合法更新真正
     送达时才降档。
   * 黄级窗口终点只决定"这一小时的密集是否计入黄级服务"，不决定配置是否继续。
   * 因此：同一策略、同一天气、**不同隐藏终点**下，配置与能耗轨迹必须逐位相同；
     `endpoint_invariance_probe` 直接验证这一点。
   * 反例（v1 的实际后果，见 §7）：v1 的求值器只把规则执行到 `down_h` 再接"此后稀疏"，于是
     "永远继续密集"的规则被评为**安全且满窗**；把 `TTL8 + 8 mWh 门`真正执行到它自己的结束时刻
     （h10），在声明的低采能未来里最低电量掉到 **0.3295 mWh**，低于 **0.47 mWh** 安全线。
   * **Task 1 与 Task 2 不得混入同一张比较表**：`valid_until`（命令携带绝对有效期）是另一种信息
     条件，单列对照。
4. **风险口径**：在**声明的全部未来**里都不得死亡（任一拍 `soc < sample_wh`）。`σ = 0` 退化为
   "只在预期采能下可行"，作为对照，不是主口径。

## 4. 三方表与恒等式

| 行 | 定义 | 求解保证 |
|---|---|---|
| 普通组合 | 声明有限族内**最强的可行成员**：固定租约 `ttl k`（**不按窗口长度截断**）、`ttl k` + 电量下限、时钟夜门、滚动预期门（开环到日落，**不以窗口末为界**） | 逐条求值取最优；启发式 |
| 非预知参照 | 上述动作族与信息集下的**精确最优**（全地平线动作；期望值反向递推 + 全未来安全求交） | 精确（在声明动作族与量化网格内） |
| 全知参照 | 逐未来取"仍能存活的最大密集小时数 k"，服务按 `12·min(k, 窗口长度)` 计，再对路径平均 | **蒙特卡洛估计，是参照不是上界** |

网格 DP 与规则求值是两条独立代码路径：DP 给出规则，规则再交给前推求值，两者必须逐位一致
（`selfcheck_service_agrees`）。核例另用**穷举可达决策格上的每一条规则**独立核对 DP。
**v1 同一动作表在 `down_h=6` 与 `=10` 下给出不同动作，正是 §3 硬约束要排除的现象。**

## 5. 可手算核例（声明实例）

核例**不复现实测数值**，作用是证明仪器有分辨力：在存在可实现差额的实例上，DP 必须能把它找出来。

| 项 | 值 |
|---|---|
| 窗口 | 2 个小时（h2、h3），地平线 4 h |
| 应用边沿电量 | 2.5 mWh（声明） |
| 终末保留量 | 2.1 mWh（声明；下游固定职责） |
| 量化 | 1e-4 Wh |
| 规模 | 可达决策格 7 个 → 穷举 128 条规则 |

**期望结果**：DP 服务 **20.0**，穷举最优同为 **20.0**；128 条规则中 96 条安全；
**最强的安全固定租约只有 12.0**，即 Δ可实现 = **+8 条/节点**。核例若给不出这个差额，
说明仪器在真问题上的"零差额"结论没有分辨力，不能采信。

## 6. 截断边界（与结论同时引用）

1. **服务 = 被采集，不是被投递**。实测中密集覆盖整个窗口时采集也只有 535/672、投递 283/672；
   应用边沿延迟与备份打包上限不在本模型内。
2. **云遮按小时取一个因子**。环境逐拍抽云，本模型抹掉逐拍抖动，只留小时级不确定。
3. **单节点切片**。不含多节点竞争、网关打包、回传可达性。
4. **动作能力限于一次租约**。不含重入、不含单次采样控制、不含新的观测通道。
5. **负载常数来自一次实测运行**（相位 A、`ttl8`、seed 0、节点 `n00`；云遮因子统计用 14 个节点）。

## 7. 校准、反例与可核对性

**常数同源**：`c5_seqref.py` 的声明常数与校准参考 `results/reference/c5_seqref_calibration.json` 的
`declared_constants` 用同一组字面量、同一表达式算出，逐位比对；实测全精度值在同文件的
`measured_constants`（偏差 ≤ 1e-9 Wh/h，当前 2.6e-11 / 5.1e-11）。

**台账校准**：把实测记录的逐小时云遮因子喂给逐拍递推，比较 49 个小时末电量；
`audit_seqref.py` 断言 `max|Δsoc| ≤ 5e-4 Wh`（实测最大 **1.13e-4 Wh**，容量的 0.23%）。

**独立反例（每次运行都必须给出，`audit_seqref.py` 逐项断言）**：

| 见证 | 期望 |
|---|---|
| "永远继续密集"规则 | 求值器的安全判定必须与**真正执行整条地平线**的结论一致（v1 判定 safe=True，真值不安全） |
| `TTL8 + 8 mWh 门`物理执行 | 执行到它自己的结束时刻，最低电量 **0.3295 mWh** < 安全线 0.47 mWh |
| 跨隐藏终点同一策略 | 配置轨迹逐位相同（真值终点 6 h 对 10 h） |
| 逐拍单调性 | 任一未来任一时刻，全程稀疏的电量不低于任何密集安排（"稀疏破线 ⇒ 无可行策略"的依据） |
| 离散化 | `std(levels(σ)) == σ`（等权三点的实际标准差，不是支撑半宽） |

## 9. 可行性前置（先判能否，再谈多少）

**顺序不能颠倒。** 负载对动作逐拍单调（密集 ≥ 稀疏），容量截断转移对电量单调，因此在任一固定未来里
**全程稀疏的轨迹是所有策略的上界**：它一旦破线，任何策略都破线。于是：

* 先对每个（相位、采光峰值、σ）判 `feasibility()`；
* 若不可行 → 报告 **"该风险口径下不存在可行策略"**，并给出破线时刻与最低电量，
  **不再**跑三方性能搜索（跑了也只能得到一族"都不可行"）；
* 若可行 → 才跑三方表，并按 §1 的判定表分别报两个差额。

`critical_sigma()` 以 **σ** 为单位报告"仍可行的最大标准差"，可直接与实测 0.047 比较。
